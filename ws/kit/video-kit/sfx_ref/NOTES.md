# 参考片学习笔记（比特新语 ×2 · 来龙去脉 ×1）

用户提供三条参考片：《光遗传学》（2026 诺贝尔生理学或医学奖，161 秒）、《擦肩》（2026 诺贝尔物理学奖 · 冰立方中微子，199 秒）。
原片不进仓库，音效也不从原片截取；下面是测量结果，`make_sfx_ref.py` 按这些数据用我们自己的代码重新合成。

## 声音（数据）

| 项目 | 参考片 | 我们（开普勒） |
| --- | --- | --- |
| 整体响度 | −15.0 LUFS（两条一致） | −19.2 LUFS |
| 60 Hz 以下能量占比 | 59% | 17% |
| 60–150 Hz 能量占比 | 13% | 52%（配乐的中低频） |

### 流星雨 + 数值增长（《擦肩》开头，用户最喜欢）
- 节奏：**每 1.000 秒一次**，和画面上的数字跳一档完全同步（62,833,333,333 → 192,833,333,333 → …）。
- 每一下 = **一声很脆的宽频“咔”**（到 18 kHz，15–20 ms 内衰减约 30 dB）+ **一声玻璃质感的提示音**（约 0.6 秒衰减）。
- 提示音音高随机取自同一组五声音阶：988 / 1048 / 1176 / 1312 / 1760 / 2096 Hz（B5 C6 D6 E6 A6 C7），不重复同一个音太多次。
- 声像略偏右（右声道比左声道高约 3 dB），和画面里流星从右上划向左下对应。
- 底下一直铺着：每秒约 22 个 2–4 kHz 的细小闪烁（“星尘”）+ 一层 30–100 Hz 的次低频长音 + 一条约每 0.17 秒一拍的中频脉冲（配乐）。
### 计数器（《擦肩》“每天一亿多个来自大气的粒子”）
- 不规则的“探测器”咔嗒声，每秒 4–6 下，间隔 0.1–0.25 秒，不是匀速。
- 数到最后接一段约 3 秒的宽频颗粒噪声（重心约 4.8 kHz），渐强后收住，接揭晓。
### 其他
- 转场很少硬切（《光遗传学》161 秒里只有约 16 个硬切），大多是暗场里的溶解和变形；声音上用上升扫频、下降扫频和低频重击衔接。

## 画面（逐帧观察）
1. **一种颜色管一幕**：深海军蓝 / 近黑底，只用一个主色（金色=视觉、绿色=藻、蓝色=神经元、橙金=中微子），配一个点缀色。
2. **发光的细线 + 粒子**：物体都是细线稿外加辉光（小鼠、手、眼球截面），大量粒子组成形状（大脑、斑马线、培养皿里的藻、星空），粒子会聚拢、散开、变形。
3. **后期质感**：辉光（bloom）、景深虚化（前景、背景模糊）、暗角、细颗粒噪点、体积光。
4. **字幕**：衬线粗体（像思源宋体），底部居中，关键词单独上色（蓝、金、橙），逐字从左到右淡入。
5. **左上角信息条**：章节名（衬线）+ 一行英文小字或文献说明（等宽小字，例如 “PETRI DISH · 俯视 · 每个绿点是一个细胞”），像论文图注。
6. **数据面板**：仪表式的数字（0.0 ms 跳动）、示波器小框、圆圈序号的步骤链、指引线连到标签；大数字会滚动增长并发光。
7. **示意声明**：右下角小字“位置为示意”。
8. **章节标题卡**：一个巨大的发光衬线字（“趋光”“擦肩”）压在主题背景上，下面一行中文副标题和疏排的英文大写。

## 封面
- 左上：金色小字点出事件（“2026 诺贝尔物理学奖”），左侧一条竖直金线。
- 巨大的白色衬线主标题（两个字），下面疏排英文大写副题（“THE ONE THAT STAYED”）。
- 右侧一个写实、发光的主体占画面一半以上（眼球、彩色指纹）。
- 左下两行钩子：第一行白色，第二行橙金色，粗体有投影；最后一行小字留悬念（“失明多年的他，然后……”“致每一个，被点亮过的人”）。

## 第三条：来龙去脉《宵禁》（426 秒，−15.0 LUFS）——“打击感”

### 打击声的解剖（敲鼓、打板子，用户最喜欢）
- 每一下分四层，按时间先后叠在一起：
  1. 一声宽频“咔”（几毫秒）；
  2. 一条从约 3 kHz 滑到约 400 Hz 的下滑音（50 ms 内），鼓身从约 130 Hz 掉到 40 Hz；
  3. **巨大的次低频鼓包**：20–80 Hz，峰值约 41 Hz，持续 250–400 ms，是整下里能量最大的部分；
  4. 一团 1–8 kHz 的颗粒噪声“啪”，80–150 ms。
- 打板子前面还有一声挥杖的风声（带通噪声从低扫到高，约 0.25 秒），“啪”落在风声的末尾。
- **越打越快**：开头敲鼓 8 下，间隔从约 3 秒缩到 0.3 秒，屏幕右上的计数同时从“2 下”跳到“1,000 下”；打板子 20 下在 5.5 秒内打完，计数 1→20 下，间隔越来越短。
- 大的打击下面，配乐会让一下（像侧链压缩），打完马上回来。

### 画面
1. **旁白不放底部**：衬线粗体，**堆在左上角**，一句接一句往下排；新的一句逐字从模糊变清楚，整组说完一起模糊淡出。
2. 关键词**加下划线并上色**：蓝色（正面、事实）和红色（惩罚、危险），引文用更大的字号加引号。
3. 右上角计数器：一行小字标签（“街鼓”“挨了”）+ 很大的衬线数字（“1,000 下”“20 下”），危险时变红，每跳一下数字轻轻一弹。
4. 统计做成**刻度条**：一根一根竖线排成的条形（“20 下 / 30 下 / 50 下”），数字用红圈圈出来。
5. 人物是**扁平的米白剪影**，配暖黄的火把光；底色是带暖意的近黑色，四角压暗。
6. 一座城 = 透视网格 + 几百个发光的小灯点；“人多”用灯点的数量来表现。
7. 大字冲击：“杖杀”“啪”这类字用红色大字砸上来，伴随屏幕抖动和放射状的冲击线。
8. 卷轴（左右两根木轴）上写竖排的律文，红字是重点，红色方印；正下方一行小字注出处（“《唐律疏议》卷二十六 · 犯夜”）。
9. 底部一条很细的**年代轴**（汉、东汉、唐、宋），亮点标出当前讲到哪里，旁边小字写公元年份。
10. 左上角有频道标识，右下角有一行很小的灰字说明。

## 我们的合成库（sfx_ref_lib.json）
meteor_1..6、count_tick、count_roll、data_burst、sparkle_bed、sub_pad、sub_drop、ui_ping_1..3、riser、downer，以及按《宵禁》解剖重新合成的 hit_drum / hit_drum2（大鼓）、hit_cane / hit_cane2（挥杖 + 落下，“啪”在样本的 0.24 秒处）、whoosh_swing、slam（大字砸屏）。

试听：`audition.mp3`（0–12 秒：次低频 + 星尘 + 每秒一颗流星；12–19 秒：计数滚动 → 颗粒噪声 → 低频重击；20–24 秒：越敲越快的鼓；24.6–28 秒：越打越快的板子；29 秒：大字砸屏）。

怎么用在片子里：见 `ws/v2/`（新质感试片《八角分》）——`tl.py` 把字幕、计数、音效、抖动都排在配乐的小节网格上，`engine.js` 是新画面引擎，`audio.py` 按小节剪配乐、在重击下让配乐、母带做到 −15 LUFS。
