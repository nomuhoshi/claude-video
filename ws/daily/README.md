# 刷牙财经（日更投资者频道）

**频道名**：刷牙财经
**简介**：刷牙的 3 分钟，听懂今天最值得关注的公司。每天更新美股、A股两条。信息整理，不构成投资建议。

## 定位（用户 2026-10-26 定下）
- 每天两条：「刷牙财经·美股」「刷牙财经·A股」。
- 每条约 3 分钟（口播约 750–850 字），刷牙时只听不看也能懂。
- **以具体公司为主，不讲太多宏观**。默认结构：
  1. 开场 15 秒：一句话大盘（指数涨跌 + 一个关键词）。
  2. 三家公司，每家约 50 秒：发生了什么 → 股价怎么动 → 对持有者意味着什么（只讲事实和要盯的点，不说买卖）。
  3. 结尾 15 秒：今天/本周要盯的一两家公司（财报日等），免责声明。
- 画面：**亮色背景**；以真实网页截图为主（行情页、新闻标题、公司公告），每张图标注来源和截图时间；不要全部用代码做动画，代码只做字幕、标注框和转场。
- 配音：暂未定（本环境连不上语音合成服务）；先只出文字稿，稿子按“说出来顺口”写。

## 每天的流程
1. 收盘后查证：指数收盘、涨跌最大且有明确原因的公司、公司公告/财报；数字用一手来源或标“转述”。
2. 写两份文字稿（`YYYY-MM-DD/us.md`、`YYYY-MM-DD/cn.md`），每份附“截图清单”（链接 + 要截哪一块）。
3. 截图：用户按清单截图发来，或会话链接到用户电脑后用浏览器截图。
4. 配音方案定下后，再做成片（亮色模板）。

## 时间口径
- A股篇：当天 15:00 收盘后做，第二天早上发。
- 美股篇：北京时间早上（美股收盘后）做，当天早上发。
