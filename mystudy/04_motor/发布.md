# 3 槽 2 极电动机：原理与制作（科普，配乐卡点）

素材：用户发来的“3スロット2極モーターの製作”讲义（葛饰校区讲义实验，6 页：原理①右手螺旋与线圈磁场、原理②三个线圈的极性与转向、1 回转部、2 BOX 部、3 电刷）。片中不提校名。
开拍问答（2026-10-22）：原理 + 制作；5–6 分钟，配乐卡点；钩子“几颗螺母 + 一根竹签就能转起来”。

## 物理模型（motor_model.py）
三角形接法，换向器 3 片（铜片中心 = φ + 30° + 120°j，缝隙 8°），电刷 + 在右、− 在左，磁铁 N 在左、S 在右。
算过 0–360° 每一度的力矩：除电刷落在缝隙的角度为 0 外，力矩全部朝顺时针，所以本片转子顺时针转。
φ = 0 时（一个线圈朝上、两个朝下，和讲义②上图同一位置）：朝上线圈外端 N（电流 1），下面两个外端 S（电流各 0.5）。
片中注明“按本片的接法；接线方式改变，转向也可能反过来”——讲义的实际接线从图上看不全，没有直接给出讲义的标准答案。

## 结构（约 5 分 24 秒，11 幕）
主题卡（第 0 帧）+ 钩子 → ① 通电导线的磁场（右手螺旋，⊗ 顺时针、⊙ 逆时针）→ ② 线圈变成磁铁（断面上 ⊙ 下 ⊗，里面向右 → 右端 N；值得记住：四指沿电流绕，拇指指向 N）→ ③ 只会转半圈 → ④ 换向器 → ⑤ 为什么要三个线圈（两线圈有死点）→ ⑥ 讲义问题：三步判断极性和转向 → ⑦ 制作：转子（大螺母 ×2、螺栓 + 小螺母、瞬间胶警告、绕线、竹签 ⌀6 mm × 11 cm + 胶带）→ ⑧ 制作：换向器（铜片压弧、双面胶、留缝、焊接）→ ⑨ 制作：盒子和电刷（厚纸 12 × 6 cm、两边 2 cm、离底 1 cm、酒精脱脂、盖子 7–8 mm 阶梯钻、磁铁、黄铜棒 + 筷子）→ 通电转起来 → 总结。

## 简介
几颗螺母、一根竹签、一卷铜线，加上两块磁铁和一节电池，就能做出一台会转的电动机。电只往一个方向流，它为什么能一直转？从右手螺旋定则讲到线圈变成电磁铁，再讲换向器怎么适时把电流反过来、为什么要三个线圈，最后把制作步骤一步步画出来。
