# 惯性力（科普，配乐卡点）

素材：用户发来的日文教材「慣性力」四页截图（EX1 电梯拉力、EX2 剪断绳子、High 等效重力、Q&A 推导 −mα、82 电车单摆、电车水面插图）。旁白用自己的话讲，片中不提书名。
开拍问答（2026-10-22）：5–6 分钟；钩子用“公交急刹车，人往前倒”；要配乐和卡点。

结构（约 5 分钟，10 幕）：主题卡（第 0 帧）+ 急刹车钩子 → 站在路边看（惯性）→ 坐在车里看（−mα）→ 为什么能补一个力（a = α + a′ 推出 ma′ = F + (−mα)）→ 三步解题 → 例一：电梯拉力 T = m(g + α) → 例二：剪断绳子 t = √(2h/(g + α))、等效重力加速度 → 例三：电车摆 tanθ = α/g、T = m√(g² + α²)、水面垂直于等效重力（图中 α = 0.4g，θ ≈ 21.8°）→ 回到急刹车 → 总结（值得记住：−mα，g + α）。
人物：乘客（蓝衣）、路边的人（绿衣）、A（地面）/ B（车上）、电梯里的人（紫裙），都是原创卡通（引擎 `person()`）。

卡点：引擎 `window.GRID`（vibe.mp3：首拍 0.391 s，一拍 0.53194 s，一小节 2.12776 s）——每幕从小节线开始、每句字幕在拍上出现、幕尾补齐到小节线；`tools/audio_grid.py` 把 vibe.mp3 按小节重拼（前奏 0–7 → 律动 A / 安静 / 律动 B 循环 → 收尾 78–85），接缝 20 ms 交叉淡化，只留转场 whoosh 和结论 ding。成片 loudnorm −14 LUFS + alimiter。

## 简介
公交急刹车，你会往前一冲——可是没有人推你。站在路边看，这只是惯性；坐在车里看，就得补上一个“惯性力” −mα，牛顿定律才能照常用。本期从 ma = F 推出惯性力从哪来，再用三个例子练一遍：电梯里绳子的拉力、电梯里剪断绳子多久落地、加速电车里的单摆和斜着的水面。

## 制作
`AUDIO=grid bash tools/render.sh 03_inertia raw.mp4`；再用 concat 列表 + audio.wav 重新封装：`-af "aresample=48000,volume=<−14.3−实测I>dB,alimiter=limit=0.66:attack=3:release=60:level=false"`。
