# 知识点 ②：周期境界条件为什么让 k 变成格点（用户 2026-10-22 发来的讲解原文要点）

1. 为什么需要边界条件：真实固体有大小 L，波必须装得进去，只有某些 k 允许。
2. 一维周期边界条件：u(x+L)=u(x) → cos(kx+kL−ωt)=cos(kx−ωt) → kL=2πn → k=2πn/L，n=0,±1,±2,…；λ=L/|n|。
   L=1 m：n=±1 → λ=1 m；±2 → 0.5 m；±3 → 0.33 m；n=0 整体平移；λ=0.7 m 不行（1.43 个波长）。负 n：向左走的波，是不同模式。
3. 三维：k=(kx,ky,kz)，|k|=2π/λ；u=A cos(k·r−ωt)；立方体 V=L³，三个方向各自首尾相接 → k=(2π/L)(nx,ny,nz)。
4. k 空间格点：间距 2π/L 的立方格子；每个格点 = 一个允许的波（固定偏振）。L=1 cm → 628 rad/m；k_max~π/a~10¹⁰ rad/m → 每方向 ~10⁷ 个 → 数格点换成算体积（A6）。
5. 为什么选首尾相接：两端固定 u(0)=u(L)=0 → k=πn/L，n=1,2,…，密度相同，D(ω) 相同；L 大时边界只影响表面；周期条件给行波，计算方便。
一句话 + 考试：k=(2π/L)(nx,ny,nz) 要写出来，是 (A) 计算的第一步。下一节 ③：数格点 → 状態密度。
