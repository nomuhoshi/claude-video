# mystudy：学习成果集大成视频

用户说“mystudy”或选这个目录时，指的就是这一类：**把用户自己推导、学完的内容，做成一支保存给自己看的视频**。不是给观众看的科普。

## 和科普片的区别

| 项目 | mystudy | 科普片 |
| --- | --- | --- |
| 受众 | 用户自己（复习、存档） | B 站观众 |
| 内容 | 专业推导，详细、不跳步；公式正规排版 | 大白话，少公式 |
| 交付 | 1080p mp4（存档用） | mp4 + 网页 + 封面 + 标题 |
| 依据 | 用户的研究笔记 / 推导稿（`notes/`），笔记就是出处 | 现查资料 + 核对表 |

## 目录

- `notes/`：用户发来的推导稿和研究笔记，按编号存（`01_泰勒展开.md`……）。
- `NN_主题/`：每支视频一个工程目录（分镜、引擎、渲染脚本）。

## 做法

- 画面沿用平时的视频风格（深蓝底、网格、金色和冰蓝），要配乐但不卡点（默认 vibe.mp3 循环，音量 0.30，片头片尾淡入淡出），字幕和轻音效照教学片。
- 公式用 MathJax 预渲染成 SVG（`tools/mktex.js`），画面里用 `tex()` 从左往右“写”出来；金色 = 这一步变化的地方；每一行右边一个标签写这一步做了什么。
- 笔记里的 `=` 如果严格说应是 `≈`，视频里按笔记的步骤走，但在那一步把符号改成 ≈ 并在字幕和画面上说明。
- 值得直接记住的公式用 `memo()` 金框标出来。
- **用户“不理解的部分”放在最后**，做成“附 · 我没想通的地方”一章，每个问题一幕（用户要求，2026-10-22）。

## 工具（`tools/`）

| 文件 | 作用 |
| --- | --- |
| `engine.js` | 推导片引擎（由 `ws/edu_wave/engine.js` 改来）：变长时间轴、字幕、左上角节标题、公式、坐标系、花括号 |
| `mktex.js` | `node tools/mktex.js NN/tex_src.js NN/out/tex.json`（先在 tools 里 `npm install`） |
| `build.py` | `python3 tools/build.py NN` → `NN/out/video.html` |
| `frames.js` | `meta` / `shots t1,t2` / 逐帧渲染 |
| `audio.py` | 轻音效 + 配乐 |
| `render.sh` | 一键：公式 → 页面 → 音频 → 两进程渲染 → 合成 mp4 |

- 先收齐笔记再开工；用户说“一会发研究笔记”时就等笔记，不先做。
- **笔记里的逐步推导，视频里也逐步显示（用户要求，2026-10-22）**：手写笔记一行一个式子，视频就一行一行写出来，顺序和笔记一致，不合并、不跳行；每一步只变一处，变化的部分高亮，并标出这一步做了什么（代入、两边乘、移项……）和依据（定义、上一步、哪条法则）。
- 手写笔记的图片也存进 `notes/`，文件名带主题和步骤号（如 `01_泰勒展开_手写_03一次近似.jpg`）。
- 数值例子在画面里真算，不手填。
- 用户偏好照旧：从第一原理讲、不跳步；值得直接记住的公式要单独标出来。

## 个人版 → 上传版
用户说“做成可以上传的视频风格”时：复制成 `NN_xxx_pub/`，开头加 20 秒钩子和路线图，删掉例子重复和附录（附录可留给下一期），旁白去掉“笔记里”等第一人称，片尾加总结和下期预告；引擎的 `window.OVERLAY` 画进度条和水印；交付 mp4 + 16:9/4:3/抖音封面 + 标题（≤20 字带字数）+ 简介 + 小红书标签。
