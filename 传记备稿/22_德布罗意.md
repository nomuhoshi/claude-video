# 22 德布罗意（Louis de Broglie，1892–1987）

## 标题候选
- 主：**德布罗意｜物质波｜科学家传记系列**（15 字）
- 备：德布罗意｜学历史的物理学家｜科学家传记系列（19 字）
- 视频内大字：**一篇博士论文说：电子也是一道波**（15 字）

## 开拍简报（草案）
- 一句话主题：一个本来要当外交官、读历史的法国贵族，被哥哥带进物理，在 1924 年的博士论文里反过来想：光既是波又是粒子，那电子也应该是波，波长 = h / 动量；答辩委员会拿不准，把论文寄给爱因斯坦，爱因斯坦说“他掀起了大幕的一角”。三年后实验证实，他凭一篇博士论文拿了诺贝尔奖。
- 观众起点：看过康普顿（光子有动量）、玻尔（特定轨道）。
- 钩子：1924 年，巴黎。一篇博士论文让答辩委员会犯了难：写得很漂亮，可结论太大胆——它说，电子也是一道波。委员们决定把它寄给一个人看看。
- 章节：贵族（迪耶普、公爵家族、哥哥莫里斯是 X 射线实验家）→ 历史学位 → 转向物理（哥哥带回的 1911 索尔维会议记录）→ 埃菲尔铁塔上的无线电兵（一战）→ 反过来想（光 = 波 + 粒子 ⇒ 电子 = 粒子 + 波）→ λ = h/p → 驻波解释玻尔轨道（周长 = 整数个波长）→ 委员会与爱因斯坦（“掀起大幕一角”）→ 薛定谔读到了 → 1927 实验（戴维孙-革末、G.P. 汤姆孙）→ 1929 诺贝尔奖 → 晚年（导航波，和哥本哈根唱反调；公爵；终身未婚）→ 1987 去世 → 电子显微镜 → 回顾。
- 不讲：相位速度与群速度的数学；双解理论的细节。
- 结尾：今天的电子显微镜，用的就是电子的波长——比光短几万倍，所以能看见病毒和原子；最后一句：“一个学历史的人，读懂了物质。”
- 配乐：Nightfall（贵族、历史）→ Entropy（反过来想、驻波）→ Awakening（爱因斯坦的评语 → 实验证实 = 高潮）→ 安静尾。
- 封面：一个电子小球后面拖着一串波纹，波纹绕着原子核刚好排成一圈整数个波峰；钩子“电子也是波”。
- 片尾剪影：一个印度达卡的年轻教师，把一篇论文装进信封，寄往柏林 → “下一期：一篇被拒稿的论文，寄给了爱因斯坦。”

## 字幕稿

**开场**
- 1924 年，巴黎大学。
- 一篇物理学博士论文，
- 让答辩委员会犯了难。
- 论文写得很漂亮，
- 可它的结论，太大胆了：
- 电子，也是一道波。
- 委员们拿不准，
- 决定把论文寄给一个人看看。
- 那个人，是爱因斯坦。
- 论文的作者，原本是学历史的。
- 他叫德布罗意。

**章节 · 贵族**

**第一幕 · 公爵家的孩子**
- 1892 年，德布罗意出生在法国北部的海边小城迪耶普，
- 他的家族，是法国最显赫的贵族之一，
- 出过元帅、总理和外交官。
- 家里希望他走外交路线。
- 他进索邦大学，读的是历史。
- 十八岁，拿到了文科学位。

**第二幕 · 哥哥的书**
- 他的哥哥莫里斯，
- 不顾家里反对，成了一个物理学家，
- 在自家宅子里建了一间 X 射线实验室。
- 1911 年，哥哥参加第一届索尔维会议，当会议秘书，
- 带回了会议的记录。
- 德布罗意读完，被普朗克和爱因斯坦的“量子”迷住了。
- 他转学物理。

**第三幕 · 埃菲尔铁塔**
- 1914 年，第一次世界大战爆发。
- 他被分到军队的无线电部门，
- 在埃菲尔铁塔上的电台工作，
- 一干就是好几年。
- 战后，他回到物理，
- 在哥哥的实验室里，和 X 射线打交道。

**章节 · 反过来**

**第四幕 · 对称**
- 那几年，光的身份已经很清楚：
- 干涉、衍射，说明它是波；
- 光电效应、康普顿散射，说明它是粒子。
- 光，两种都是。
- 德布罗意想：
- 大自然喜欢对称。
- 既然一直被当成波的光，也是粒子，
- 那一直被当成粒子的电子，
- 为什么不能也是波？

**第五幕 · 波长**
- 他借用光子的关系：
- 光子的动量，等于 h 除以波长。
- 反过来，
- 任何一个运动的粒子，都应该有一个波长：
- 波长，等于 h 除以它的动量。
- λ = h / p。
- 普朗克常数 h 极小，
- 所以一颗网球的波长小到毫无意义；
- 可电子极轻，
- 它的波长，和原子差不多大。

**第六幕 · 绕一圈**
- 然后，他发现了一件美妙的事。
- 玻尔说，电子只能待在几条特定的轨道上，
- 可玻尔说不出为什么。
- 如果电子是一道波，
- 绕着原子核转一圈，回到起点，
- 波峰必须和自己接上。
- 周长，必须正好是整数个波长。
- 一个、两个、三个……
- 不是整数，波就会自己抵消掉。
- 玻尔那几条神秘的轨道，
- 正好就是这些能“首尾相接”的轨道。

**章节 · 一封信**

**第七幕 · 大幕的一角**
- 1924 年，他把这些写成了博士论文。
- 委员会里的朗之万，
- 把论文寄给了爱因斯坦。
- 爱因斯坦回信说：
- 他掀起了大幕的一角。
- 论文通过了。

**第八幕 · 薛定谔**
- 爱因斯坦在自己的论文里，
- 向大家推荐了这个想法。
- 苏黎世有一位物理学家读到了，
- 他想：如果电子是波，
- 那它应该满足一个波动方程。
- 方程是什么？
- 他叫薛定谔。

**第九幕 · 证实**
- 如果电子是波，
- 它打到晶体上，就会像 X 射线一样，
- 在某些角度特别强。
- 1927 年，美国的戴维孙和革末，
- 用电子打镍晶体，看到了。
- 同一年，英国的乔治·汤姆孙——
- 发现电子的那位汤姆孙的儿子——
- 让电子穿过金属薄片，看到了一圈圈的衍射环。
- 波长，正好等于 h 除以动量。

**第十幕 · 诺贝尔奖**
- 1929 年，德布罗意获得诺贝尔物理学奖。
- 他的诺贝尔奖，来自五年前那篇博士论文里的想法。

**章节 · 晚年**

**第十一幕 · 导航波**
- 后来，量子力学说：
- 电子的波，只代表它出现在某处的概率。
- 德布罗意不太满意。
- 他想过另一种解释：
- 电子是一颗真实的粒子，
- 被一道真实的波“导航”着走。
- 1927 年的索尔维会议上，这个想法被批评，
- 他放弃了。
- 二十多年后，美国物理学家玻姆重新发展了它，
- 德布罗意又回到了自己的想法。
- 今天，这种解释仍然有人研究。

**第十二幕 · 公爵**
- 他终身没有结婚，
- 生活简单，几乎一辈子住在巴黎。
- 哥哥去世后，他继承了公爵的头衔。
- 1987 年 3 月 19 日，德布罗意在巴黎去世，
- 九十四岁。

**结尾**
- 今天的电子显微镜，用的正是电子的波长。
- 它比可见光短几万倍，
- 所以能看见病毒，看见原子。
- 一个学历史的人，读懂了物质。

**回顾**：公爵家族 → 历史学位 → 哥哥的会议记录 → 埃菲尔铁塔 → 反过来想 → λ = h/p → 绕一圈首尾相接 → 大幕的一角 → 电子衍射 → 电子显微镜

**片尾剪影**
- 就在同一年，1924 年，
- 爱因斯坦还收到了另一篇论文。
- 它来自印度，作者被期刊拒了稿。
- 下一期：一篇被拒稿的论文，寄给了爱因斯坦。

## 值得记住（给用户）
- 德布罗意关系 λ = h / p（以及 E = hν）。玻尔量子化条件 2πr = nλ ⇔ mvr = nħ，记住这个对应即可。

## 已查证 / 写“据说” / 不写
已核实（MacTutor、Britannica、利奥波第那科学院 CV）：
- 1892 年 8 月 15 日生于迪耶普，父亲是德布罗意公爵；1909 年中学毕业；入索邦准备从事外交，18 岁获文科学位；1913 年理学学士。
- 一战在埃菲尔铁塔的无线电报站服役。
- 1924 年博士论文《量子理论研究》提出电子波。
- 1927 年戴维孙、革末（与 Kunsman）和 G.P. 汤姆孙证实。
- 1928 年庞加莱研究所教授；1929 年诺贝尔奖；1933 年科学院院士；1942 年科学院终身秘书。
- 1956 年“双解理论”，晚年回到“统计理论背后有确定实在”的观点。
- 1987 年 3 月 19 日在巴黎去世。

写“据说/开拍再核”：
- 哥哥莫里斯是 1911 年索尔维会议秘书、带回记录：德布罗意自述（诺贝尔演讲及传记），开拍再核。
- 朗之万寄给爱因斯坦、“他掀起了大幕的一角”（法文 Il a soulevé un coin du grand voile）：常见引用，开拍核信件出处。
- “第一次凭博士论文获奖”：常见说法，但措辞改成“他的诺贝尔奖，来自博士论文里的想法”更稳。
- 1944 年入选法兰西学院（Académie française）、1960 年继承公爵、终身未婚：开拍再核。
- 1927 年索尔维会议受批评后放弃，1952 年玻姆重提后回归：通行物理史。

不写：德布罗意-玻姆理论与贝尔不等式的细节。
