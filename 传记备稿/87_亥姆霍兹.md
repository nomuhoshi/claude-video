## 开拍简报（草案）
- 一句话主题：波茨坦一位中学老师的儿子亥姆霍兹，喜欢物理，却因为家里没钱，只能去读学费全免的军医学校（要以服役作为交换 → 开拍核）；当军医时，他在业余时间思考一个大问题：自然界里的各种“力”——机械的、热的、电的、化学的、生命的——能不能互相转换，总量是不是不变？1847 年，26 岁的他发表了《论力的守恒》，第一次把能量守恒定律写成了最普遍的形式。他又是生理学家：测出了神经传导的速度，发明了检眼镜，研究人怎么看颜色、怎么听声音。他的学生里有赫兹和普朗克。
- 观众起点：看过 86 焦耳（热功当量）、mystudy 02 能量守恒教学片（**强烈建议联动**）。
- 物理部分（不推导）：
  1. **能量守恒**：能量既不会凭空产生，也不会凭空消失，只会从一种形式变成另一种形式，总量不变（**必考**）。热力学第一定律 ΔU = Q + W（**值得记**）。
  2. **永动机为什么不可能**：第一类永动机（不消耗能量就能一直做功）违反能量守恒。
  3. **神经有多快**：他用青蛙的神经和肌肉，在神经的两个不同位置刺激，比较肌肉收缩的时间差，算出神经信号的速度大约每秒二三十米——比当时人们以为的“快得测不出来”慢得多（开拍核数值）。
  4. **检眼镜**：用一面镜子把光照进眼睛，同时从镜子中间的小孔看进去，第一次看清了活人的视网膜。
  5. **亥姆霍兹共鸣器**（一句话）：对着瓶口吹气，瓶子会“呜”地响——空腔的共振。
- 钩子：1847 年，柏林物理学会。一位 26 岁的普鲁士军医站起来演讲，题目是《论力的守恒》。“他说：自然界里所有形式的‘力’，加起来的总量，永远不变。”
- 章节：波茨坦（1821，父亲是中学教师）→ 想学物理，家里负担不起 → 读柏林的军医学校（毕业后要当几年军医）→ 波茨坦当军医，业余做实验 → 当时的“生命力”学说：生命有一种特殊的力 → 他想证明生命也遵守物理规律 → 1847《论力的守恒》（开拍核：《物理学年鉴》拒稿，他自己印成小册子）→ 能量守恒的普遍形式（焦耳、迈尔也各自得到 → 一句话）→ 柯尼斯堡、波恩、海德堡、柏林的教授 → 1849–50 年测神经速度 → 1851 年检眼镜 → 视觉（三色理论，回扣托马斯·杨）、听觉（音色、共鸣器，回扣傅里叶）→ 学生赫兹、普朗克 → 1883 年封贵族“冯” → 1894 年 9 月 8 日去世 → 德国最大的科研机构亥姆霍兹联合会以他命名 → 回顾。
- 不讲：涡旋、电动力学的细节。
- 结尾：“从青蛙的一根神经，到整个宇宙，能量的账本从来没有出过错。”
- 配乐：Entropy（军医钩子）→ Awakening（能量守恒 = 高潮）→ 轻快（神经测速、检眼镜）→ 尾。
- 封面：一张能量转换图：重物下落 → 桨叶 → 热；电池 → 灯；食物 → 肌肉，中心写着“总量不变”；钩子“能量守恒”。
- 片尾剪影（按内容顺序）：1865 年苏黎世，一位德国物理学家为一个新的物理量造了一个词，故意让它听起来像“能量” → “下一期：熵。”

## 字幕稿

**开场**
- 1847 年，柏林物理学会。
- 一位二十六岁的普鲁士军医，站起来做演讲，
- 题目叫《论力的守恒》。
- 他说：
- 自然界里，各种形式的“力”——
- 运动的、热的、电的、化学的，甚至生命的，
- 可以互相转化，可加起来的总量，永远不变。
- 今天，我们叫它：能量守恒。
- 他叫亥姆霍兹。

**章节 · 军医**

**第一幕 · 波茨坦**
- 1821 年，亥姆霍兹出生在德国波茨坦，
- 父亲是一位中学老师。
- 他从小就喜欢物理。
- 可家里没钱供他读大学学物理。

**第二幕 · 军医学校**
- 他找到了一条路：
- 柏林有一所培养军医的学校，学费全免，
- 条件是毕业后要在军队里当几年医生。（开拍核）
- 于是，他学了医。

**第三幕 · 业余**
- 毕业后，他在波茨坦的军营里当军医。
- 业余时间，他在自己的小实验室里做研究。
- 他想解决一个问题：
- 当时很多人相信，生物体里有一种特殊的“生命力”，
- 不遵守物理和化学的规律。
- 亥姆霍兹不信。

**章节 · 守恒**

**第四幕 · 永动机**
- 他想到了永动机。
- 几百年来，无数人想造一台不用加燃料、
- 却能一直转下去、一直做功的机器，
- 没有一个人成功。
- 亥姆霍兹想：
- 也许，这不是技术问题，而是自然界本来就不允许。

**第五幕 · 一本账**
- 他把力学、热、电、磁、化学，
- 各个领域里的现象，一个一个地算：
- 重物落下，变成了热；
- 电池放电，变成了热和化学变化；
- 食物在身体里，变成了肌肉的运动和体温。
- 每一种转化，都可以算出一个固定的“兑换率”。
- 总的账本，永远是平的。

**第六幕 · 1847**
- 1847 年，他把这些写成了一篇论文。
- 据说，当时的物理学顶级期刊不肯发表，觉得太空泛，
- 他只好自己印成了一本小册子。（开拍核）
- 差不多同时，英国的焦耳、德国的医生迈尔，
- 也从不同的方向，走到了同一个结论。
- 而亥姆霍兹，把它写成了最普遍、最清楚的形式。

**章节 · 青蛙和眼睛**

**第七幕 · 神经有多快**
- 当时，人们以为神经信号快得无法测量。
- 1849 年，亥姆霍兹用青蛙的腿做实验：
- 在神经的远处刺激一下，又在近处刺激一下，
- 比较肌肉收缩的时间差。
- 他算出：神经信号的速度，大约每秒几十米。
- 比声音还慢得多。

**第八幕 · 看见视网膜**
- 1851 年，他发明了检眼镜：
- 用一面镜子把光照进眼睛，
- 同时从镜子中间的小孔看进去，
- 第一次看清了活人眼睛底部的视网膜。
- 今天，眼科医生还在用它的后代。

**第九幕 · 颜色和声音**
- 他研究人怎么看到颜色，
- 发展了托马斯·杨的三色理论；
- 他研究人怎么听声音，
- 解释了为什么不同的乐器，有不同的音色。
- 对着瓶口吹气，瓶子会发出“呜”的声音——
- 这种空腔的共鸣，今天叫“亥姆霍兹共鸣器”。

**章节 · 之后**

**第十幕 · 老师**
- 后来，他成了德国最有名的科学家之一，
- 先后在好几所大学当教授，最后到了柏林。
- 他的学生里，有发现电磁波的赫兹，
- 有打开量子大门的普朗克。
- 1883 年，他被封为贵族，名字前加上了“冯”。
- 1894 年，亥姆霍兹去世，七十三岁。

**结尾**
- 今天，德国最大的科研机构，以他的名字命名。
- 从青蛙的一根神经，到整个宇宙，
- 能量的账本，从来没有出过错。

**回顾**：力的守恒 → 中学老师的儿子 → 军医学校 → 业余实验 → 生命力 → 永动机 → 一本账 → 1847 → 焦耳和迈尔 → 青蛙的神经 → 检眼镜 → 颜色和声音 → 共鸣器 → 赫兹和普朗克

**片尾剪影（按内容顺序）**
- 1865 年苏黎世，一位德国物理学家为一个新的物理量造了一个词，故意让它听起来像“能量”。
- “下一期：熵。”

## 值得记住（给用户）
- 能量守恒；热力学第一定律 ΔU = Q + W（W 为外界对系统做的功）。**必考。**
- 第一类永动机不可能（违反第一定律）。

## 查证结果（2026-10-23 网页核对）
**已核实**
- 视觉与听觉科学研究的先驱；1851 年发明检眼镜；著《生理光学手册》；约 1849–1850 年用青蛙测量神经信号速度。
- 1847 年《论力的守恒》以最普遍的形式表述能量守恒；在流体力学、电动力学、热力学都有贡献。
- 在柯尼斯堡、波恩、海德堡、柏林任职；学生包括普朗克、赫兹。
- 1883 年封贵族，故称“冯·亥姆霍兹”；亥姆霍兹联合会以他命名。
