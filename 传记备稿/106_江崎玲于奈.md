## 开拍简报（草案）
- 一句话主题：大阪出生的江崎玲于奈，1947 年从东京帝国大学物理系毕业，先在一家做真空管的公司工作（神户工业 → 开拍核），1956 年进入当时还很小的东京通信工业（后来的索尼）做半导体研究。1957 年，他在研究一种极薄的锗 p-n 结时发现了一件反常的事：电压加大，电流反而变小了。他意识到，这是电子在“穿墙”——量子隧穿效应第一次在固体器件里被清楚地看到并利用。由此诞生的“江崎二极管”（隧道二极管）让他在 1959 年拿到博士学位、1973 年获得诺贝尔奖。1960 年他去了美国 IBM 研究中心，又和朱兆祥（Raphael Tsu）一起提出了“半导体超晶格”——用一层层只有几个原子厚的材料，人工造出自然界没有的晶体。后来他回到日本，担任筑波大学校长。
- 观众起点：看过 58 伽莫夫（α 衰变 = 隧穿）、43 巴丁（晶体管）、98 黄昆（晶格）。
- 物理部分（不推导）：
  1. **隧穿回顾**（回扣 58 伽莫夫）：一个球滚向一座小山，能量不够，经典物理说它一定会被弹回来；量子力学说，它有一定概率直接出现在山的另一边——像穿墙一样。墙越薄，穿过去的概率越大（**值得记**：穿透概率随墙厚度指数衰减，T ∝ e^(−2κd)，只记“指数”这个结论）。
  2. **p-n 结**（直觉）：两种不同的半导体贴在一起，交界处形成一层“墙”（耗尽层），电子要翻过去才能导电——这就是二极管单向导电的原因。
  3. **把墙做得极薄**：如果掺杂极重，这堵墙会薄到只有大约十纳米（开拍核），电子就不用翻墙，可以直接“穿”过去。
  4. **负电阻**：在某一段电压里，电压加大，能穿墙的电子反而变少，电流下降——普通电阻是电压越大电流越大，这里正好相反。这种“负电阻”可以用来做极快的振荡器和开关。
  5. **超晶格**（一句话）：把两种半导体一层一层地交替堆起来，每层只有几纳米，电子在里面的行为可以被“设计”——今天的半导体激光器、高速晶体管都用到了类似的想法（开拍核措辞）。
- 钩子：一条电流-电压曲线。普通的二极管：电压越大，电流越大。镜头切到 1957 年的一条曲线：电压加大，电流先上升，然后——掉了下去。“这在当时的教科书里，是不可能的。”
- 章节：大阪出生（1925）→ 东京帝国大学物理系，1947 年毕业 → 真空管公司（神户工业 → 开拍核）→ 1956 年东京通信工业（后来的索尼），研究锗晶体管 → 1957 年：极薄的锗 p-n 结，电流-电压曲线的反常 → 意识到：隧穿 → 江崎二极管 → 1959 年博士 → 1960 年 IBM 沃森研究中心 → 1969–1970 年和朱兆祥提出超晶格 → 1973 年诺贝尔奖（和贾埃沃、约瑟夫森——三个人都和“隧穿”有关）→ 回到日本，担任筑波大学校长（至 1998 年）→ 1994 年林道诺奖得主大会上，提出给年轻科学家的“五不”（开拍核原文，字幕只意译）→ 回顾。
- 不讲：私生活；对其他人的评价。
- 结尾：“半个世纪前，他看到了一条‘不可能’的曲线。他没有把它当成测量错误，而是问：这是不是电子在穿墙？”
- 配乐：安静（曲线钩子）→ Entropy（战后东京）→ 紧张（反常曲线）→ Awakening（隧穿 = 高潮）→ 尾。
- 封面：一条先升后降的曲线，旁边一个电子从一堵墙里穿出；钩子“穿墙的电子”。

## 字幕稿

**开场**
- 这是一条普通二极管的曲线：
- 电压越大，电流越大。
- 这是 1957 年，东京一间实验室里测出的一条曲线：
- 电压加大，电流先上升，
- 然后，掉了下去。
- 按当时的教科书，这是不可能的。
- 测出这条曲线的人，叫江崎玲于奈。

**章节 · 半导体**

**第一幕 · 大阪**
- 1925 年，江崎玲于奈出生在大阪。
- 1947 年，他从东京帝国大学物理系毕业。
- 那时，战争刚刚结束，
- 他先进了一家做真空管的公司。（开拍核）

**第二幕 · 东京通信工业**
- 1956 年，他换到了一家还很小的公司：东京通信工业。
- 这家公司，后来改名叫索尼。
- 那时，晶体管刚发明不久，
- 公司想用它来做收音机。
- 江崎的工作，是研究晶体管里用的锗。

**章节 · 穿墙**

**第三幕 · 一堵墙**
- 二极管为什么只让电流往一个方向走？
- 因为两种半导体贴在一起的地方，
- 会形成一堵“墙”。
- 电子要翻过这堵墙，电流才能通过。

**第四幕 · 反常的曲线**
- 江崎想知道，
- 如果把这堵墙做得越来越薄，会怎么样？
- 他做出了极薄的锗二极管，
- 然后，测到了那条奇怪的曲线：
- 在某一段，电压加大，电流反而变小。
- 他没有把它当成测量出了错。

**第五幕 · 隧穿**
- 他意识到：这是量子力学里的“隧穿”。
- 三十年前，伽莫夫用它解释了 α 粒子怎样逃出原子核：
- 一个粒子能量不够，翻不过一堵墙，
- 却有一定的概率，直接出现在墙的另一边。
- 墙越薄，穿过去的概率越大。
- 现在，江崎的二极管里，
- 墙薄到只有大约十纳米，（开拍核）
- 电子不用翻墙，直接穿了过去。

**第六幕 · 负电阻**
- 而在某一段电压里，
- 电压加大，能穿过墙的电子反而变少，
- 电流就下降了。
- 这叫“负电阻”。
- 这种二极管反应极快，可以用来做高速的开关和振荡器。
- 它后来被叫作“江崎二极管”，也叫“隧道二极管”。
- 这是人类第一次，在固体器件里清楚地看到并利用了隧穿效应。

**章节 · 之后**

**第七幕 · IBM**
- 1959 年，江崎凭这项研究拿到了博士学位。
- 1960 年，他去了美国 IBM 的研究中心。

**第八幕 · 超晶格**
- 在那里，他和朱兆祥提出了一个新想法：
- 把两种半导体，一层一层地交替堆起来，
- 每一层只有几纳米厚。
- 这种人工造出来的“超晶格”，
- 能让电子按照人设计的方式运动。
- 今天的很多半导体激光器和高速器件，都用到了类似的结构。（开拍核）

**第九幕 · 1973**
- 1973 年，江崎玲于奈获得了诺贝尔物理学奖，
- 和贾埃沃、约瑟夫森一起分享。
- 三个人的工作，都和“隧穿”有关。

**第十幕 · 筑波**
- 后来，他回到日本，担任了筑波大学校长。
- 1994 年，在德国林道的诺贝尔奖得主大会上，
- 他给年轻的科学家们提了五条建议，
- 其中一条大意是：
- 不要忘了你孩子般的好奇心。（开拍核原文）

**结尾**
- 半个世纪前，他看到了一条“不可能”的曲线。
- 他没有把它当成测量错误，
- 而是问：这会不会是电子在穿墙？

**回顾**：不可能的曲线 → 大阪 → 东京通信工业（索尼）→ 一堵墙 → 把墙做薄 → 反常 → 隧穿 → 伽莫夫 → 负电阻 → 江崎二极管 → IBM → 超晶格 → 1973 → 筑波 → 好奇心

**片尾剪影（按内容顺序）**
- 1998 年，岐阜县高山市的一场国际会议上，一位日本物理学家宣布：中微子在飞行的路上，会变成另一种中微子。
- “下一期：会变身的粒子。”

## 值得记住（给用户）

- 负微分电阻：dI/dV < 0。
