## 开拍简报（草案）
- 一句话主题：黄昆考清华和北洋都没考上（据说是国文作文吃亏），去了燕京大学，在课业不重的大三大四自学了量子力学；在昆明西南联大读研究生时，他和杨振宁、张守廉被称为“三剑客”，常常为量子力学的测量问题争到深夜。他到英国布里斯托尔大学跟着莫特读博士，发现了一种 X 射线漫散射（后来叫“黄散射”）；之后在利物浦，他和量子力学的奠基人玻恩合写了《晶格动力学理论》——玻恩在序言里说，这本书的最终形式和写作，基本上归功于黄博士。他和英国同事艾芙·里斯提出了描述电子与晶格振动耦合的“黄-里斯理论”，后来两人结为夫妻。1951 年他回到北京大学任教，为中国培养了第一批半导体人才；2001 年获得国家最高科学技术奖。
- 观众起点：看过 26 玻恩（A 档第一季已备稿）、43 巴丁（半导体）、44 杨振宁与李政道（西南联大）。
- 物理部分（不推导）：
  1. **晶格**：固体里的原子排成整齐的阵列，原子之间就像用小弹簧连着（回扣 71 胡克）。
  2. **晶格振动**：一个原子动一下，会带着邻居一起振动，像一串弹簧连起来的小球，振动以波的形式传遍整个晶体。按量子力学，这种振动的能量是一份一份的，每一份叫一个“声子”（**值得记**：声子能量 E = ħω）。固体的比热、热传导、电阻随温度的变化，都和声子有关。
  3. **黄-里斯理论**（直觉）：晶体里的电子跳到另一个能级时，会顺便“拽动”周围的原子，让晶格也振动起来——所以晶体发出的光，颜色会变宽、变偏。
  4. **极化激元**（一句话）：在某些晶体里，光和晶格振动会“混”在一起，变成一种新的波——黄昆最早给出了这个理论（开拍核：黄方程 1951）。
- 钩子：1954 年，英国牛津出版社出版了一本固体物理的经典著作，作者是诺贝尔奖得主玻恩和一位年轻的中国物理学家。玻恩在序言里写道：这本书的最终形式和写作，基本上归功于黄博士。“那时，这位黄博士已经回到中国好几年了。”
- 章节：求学（随父亲从上海搬到北京，连跳三级）→ 考清华、北洋落榜（国文作文吃亏）→ 燕京大学：课业不重，自学量子力学 → 西南联大研究生，导师吴大猷 → “三剑客”：和杨振宁、张守廉同住，争论量子力学到深夜（杨振宁的回忆）→ 赴英留学：布里斯托尔大学，导师莫特，1948 年博士，“黄散射” → 莫特的影响：从具体问题出发、建立模型 → 利物浦博士后 → 和玻恩合写《晶格动力学理论》：他坚持先写“基础理论”的入门章节，玻恩勉强同意；今天读者最多的，正是这些章节 → 1950 年和艾芙·里斯提出黄-里斯理论，第二年两人结婚（她后来随他来到中国，取中文名李爱扶 → 开拍核）→ 1951 年回国，北京大学物理系 → 教学：讲课以清楚著称（开拍核）→ 半导体物理的教学与人才培养（1956 年五校联合半导体专门化 → 开拍核）→ 1955 年中科院学部委员 → 1977 年中科院半导体所所长 → 1988 年黄-朱模型 → 2001 年国家最高科学技术奖 → 2005 年 7 月 6 日在北京去世 → 回顾。
- 不讲：政治运动中的经历（按用户要求不展开政治叙事）。
- 结尾：“今天，你手机里的每一块芯片，都离不开对晶体中电子和原子振动的理解。那本 1954 年的书，至今仍在再版。”

## 字幕稿

**开场**
- 1954 年，英国牛津大学出版社出版了一本书：
- 《晶格动力学理论》。
- 作者有两位：
- 一位是量子力学的奠基人之一、诺贝尔奖得主玻恩，
- 一位是年轻的中国物理学家。
- 玻恩在序言里写道：
- 这本书的最终形式和写作，基本上归功于黄博士。
- 他叫黄昆。

**章节 · 求学**

**第一幕 · 跳级**
- 1919 年，黄昆出生。
- 小时候在上海读小学，父亲工作调到北京，
- 他从小学五年级，直接跳到了初中二年级。

**第二幕 · 落榜**
- 中学毕业，他报考清华大学和北洋大学，
- 都没有考上——据说，是国文作文吃了亏。
- 他进了燕京大学物理系。

**第三幕 · 自学量子力学**
- 燕京大学物理系的课程不算重。
- 大三、大四两年，他用多出来的时间，
- 自己啃完了刚刚诞生不久的量子力学。

**章节 · 三剑客**

**第四幕 · 西南联大**
- 抗战期间，他到昆明的西南联大读研究生，
- 导师是物理学家吴大猷。

**第五幕 · 三剑客**
- 在西南联大，他和杨振宁、张守廉住在一起，
- 三个人被同学们称为“三剑客”。
- 他们经常为量子力学里最玄妙的问题——测量到底是什么——
- 争论到深夜，
- 熄了灯，还躺在床上继续吵。
- 很多年后，杨振宁还记得那些夜晚。

**章节 · 英国六年**

**第六幕 · 莫特**
- 1945 年，他考取留英名额，
- 到英国布里斯托尔大学，跟着固体物理学家莫特读博士。
- 他研究晶体里的杂质原子怎样影响 X 射线的散射，
- 发现了一种新的散射现象，后来被叫作“黄散射”。
- 莫特教会了他一种做研究的方法：
- 从具体的物理问题出发，抓住本质，建立模型。

**第七幕 · 和玻恩写书**
- 博士毕业后，他到利物浦大学做研究，
- 并开始和玻恩合作，写一本关于晶体的书。
- 玻恩原本准备了一套很一般、很抽象的理论。
- 黄昆坚持：要先写几章入门的“基础理论”，
- 让读者从具体的例子开始理解。
- 玻恩勉强同意了。
- 后来证明，这几章，恰恰是这本书被读得最多的部分。

**章节 · 晶格**

**第八幕 · 小弹簧**
- 什么是晶格？
- 固体里的原子，排成一个个整齐的阵列，
- 原子和原子之间，就像用一根根小弹簧连着。

**第九幕 · 声子**
- 一个原子动一下，会带着旁边的原子一起振动，
- 振动像波一样，传遍整个晶体。
- 按照量子力学，这种振动的能量是一份一份的，
- 每一份，叫一个“声子”。
- 固体为什么会导热、电阻为什么随温度变化，
- 都和这些声子有关。

**第十幕 · 黄-里斯**
- 1950 年，他和英国同事艾芙·里斯一起，
- 研究晶体里的电子跳到另一个能级时会发生什么。
- 他们发现：电子跳的时候，会顺便拽动周围的原子，
- 让晶格也跟着振动起来，
- 所以晶体发出的光，颜色会变宽、变偏。
- 这被称为“黄-里斯理论”。
- 第二年，黄昆和艾芙结婚了。
- 后来，她跟着他来到中国，在北京生活了一辈子。（开拍核）

**章节 · 回国**

**第十一幕 · 北京大学**
- 1951 年，黄昆回到中国，成为北京大学物理系的教授。
- 那本和玻恩合写的书出版时，他已经在北京教书好几年了。
- 他讲课以清楚、透彻著称，
- 为中国培养了第一批固体物理和半导体的人才。（开拍核）

**第十二幕 · 半导体**
- 后来，他担任中国科学院半导体研究所所长，
- 晚年还和学生一起，提出了新的理论模型。
- 2001 年，他获得了国家最高科学技术奖。
- 2005 年 7 月，黄昆在北京去世，八十五岁。

**结尾**
- 今天，你手机里的每一块芯片，
- 都离不开对晶体中电子和原子振动的理解。
- 那本 1954 年出版的书，到今天还在再版。

**回顾**：玻恩的序言 → 跳级 → 落榜 → 燕京大学 → 自学量子力学 → 西南联大 → 三剑客 → 争论到深夜 → 莫特 → 黄散射 → 和玻恩写书 → 基础理论章节 → 小弹簧 → 声子 → 黄-里斯 → 艾芙 → 北京大学 → 半导体

## 值得记住（给用户）
- 声子：晶格振动的能量量子，E = ħω。**值得记。**
- 一维单原子链色散关系 ω = 2√(k/m)|sin(qa/2)|（大学固体物理，了解即可）。

## 查证结果（2026-10-23 网页核对）
**已核实**
- 1919 年 9 月 2 日生（Wikipedia 写出生于浙江嘉兴；常见中文资料写“生于北京，祖籍嘉兴”，开拍核，字幕没写出生地），2005 年 7 月 6 日在北京去世。
- 燕京大学物理学士；西南联大研究生，导师吴大猷；1948 年布里斯托尔大学博士，导师莫特。
- 利物浦大学博士后期间与玻恩合写《晶格动力学理论》（1949–1951 年写作）；玻恩-黄近似以二人命名。
- 研究成果：黄散射（博士论文）、极化激元理论、黄-里斯因子（1950，与艾芙·里斯，一年后两人结婚）、黄-朱模型（1988）。
- 1951 年回国任北京大学物理教授；1955 年中科院学部委员；1977 年起任中科院半导体所所长。
- 1980 年瑞典皇家科学院外籍院士、1985 年第三世界科学院院士、1996 年陈嘉庚奖、2001 年国家最高科学技术奖。
- 上海光华小学、随父迁京连跳三级（五年级跳到初二）；考清华、北洋未中（似因国文作文），进燕京；大三大四自学量子力学；西南联大与杨振宁、张守廉被称为“三剑客”，争论量子测量问题到深夜（杨振宁回忆）；坚持在书中加入“基础理论”章节，玻恩勉强同意；玻恩序言称该书最终形式和写作“基本上归功于黄博士”；这些章节至今被读得最多（清华大学文章）。
