## 开拍简报（草案）
- 一句话主题：两千两百多年前，北非昔兰尼出生的埃拉托色尼，做了亚历山大图书馆的馆长。他听说，在南方的赛伊尼，夏至正午太阳会直射，井底都能照到阳光；可同一时刻在亚历山大，竖一根木棍还会有影子。他测出影子的角度大约是一整圈的五十分之一，再乘上两座城之间的距离，算出了地球的周长。他的结果和今天的值惊人地接近——虽然这里面有一点运气。
- 观众起点：无需前置，适合新观众。
- 物理部分（不推导，几何直觉）：
  1. **太阳光是平行的**：太阳离我们极远，照到地球上的光线几乎完全平行。
  2. **两地两个角**：赛伊尼的光线直直照进井底（竖直），亚历山大的木棍和光线成大约 7.2°。因为光线平行，这个 7.2° 正好等于两座城市在地心处张开的角度（平行线的内错角相等，初中几何）。
  3. **一份乘以五十**：7.2° 是一整圈 360° 的 1/50，所以地球周长 = 两城距离 × 50（**值得记**：弧长 s = Rθ；地球周长约 4 万公里，半径约 6400 公里）。
  4. **运气的成分**：赛伊尼其实不完全在北回归线上，也不正好在亚历山大的正南方；两个误差恰好互相抵消了一部分。“斯塔德”这个长度单位到底多长，今天也有争议。
- 钩子：夏至正午，埃及南方，一口深井，阳光直直照到井底的水面。同一时刻，八百公里外，一根木棍在地上投下一小段影子。“这两件事，就能算出地球有多大。”（距离开拍核）
- 章节：昔兰尼出生 → 雅典求学（开拍核）→ 受托勒密三世邀请到亚历山大，任图书馆馆长 → 什么都懂一点，被戏称“贝塔”（第二名 → 开拍核）→ 赛伊尼的井 → 亚历山大的木棍 → 1/50 圈 → 5000 斯塔德 × 50 → 约 25 万斯塔德 → 和今天的值比较 → 两个误差互相抵消 → 也做地理（据说“地理学”一词出自他 → 开拍核）、质数“筛法”（一句话）→ 晚年失明，据说绝食而死（传说 → 开拍核，可不写）→ 回顾。
- 不讲：斯塔德换算的学术争论细节（一句话带过）。
- 结尾：“他没有离开过地面，只用一根木棍、一个角度、一段距离，就量出了整个世界。”
- 配乐：古典竖琴（钩子）→ Entropy（图书馆）→ Awakening（乘以五十 = 高潮）→ 尾。
- 封面：地球剖面，两束平行的阳光，一束照进井底，一束斜照木棍，地心处一个 7.2° 的小角；钩子“量出地球周长”。

## 字幕稿

**开场**
- 夏至的正午，埃及南方的一座城市。
- 一口深井，阳光直直地照到了井底的水面。
- 同一时刻，在北方的亚历山大，
- 一根竖直的木棍，在地上投下了一小段影子。
- 两千两百多年前，有一个人，
- 用这两件事，算出了地球有多大。
- 他叫埃拉托色尼。

**章节 · 图书馆**

**第一幕 · 昔兰尼**
- 公元前三世纪，埃拉托色尼出生在北非的昔兰尼。
- 后来，他被请到埃及的亚历山大，
- 做了当时世界上最大的图书馆的馆长。

**第二幕 · 贝塔**
- 他什么都研究：数学、天文、地理、诗歌、历史。
- 据说，同时代的人给他起了个外号，叫“贝塔”，
- 意思是：样样都是第二名。（开拍核）

**章节 · 一根木棍**

**第三幕 · 南方的井**
- 他听说，在南方的赛伊尼，
- 每年夏至的正午，太阳正好在头顶，
- 阳光能直直地照到井底。

**第四幕 · 北方的影子**
- 可是同一时刻，在亚历山大，
- 一根竖直的木棍，还是会有影子。
- 他量出：阳光和木棍之间的角度，
- 大约是一整圈的五十分之一，
- 也就是 7.2 度。

**第五幕 · 平行的光**
- 太阳离我们极远，照到地球上的光线几乎是平行的。
- 如果大地是平的，两根木棍的影子应该一样长。
- 影子不一样长，说明大地是弯的。
- 而那 7.2 度，
- 正好等于两座城市在地球中心张开的角度。

**第六幕 · 乘以五十**
- 7.2 度是一整圈的五十分之一。
- 那么，两座城市之间的距离，
- 就是地球周长的五十分之一。
- 两座城市相距大约五千斯塔德，
- 乘以五十，地球的周长，大约是二十五万斯塔德。

**章节 · 有多准**

**第七幕 · 惊人的接近**
- 一斯塔德到底有多长，今天的学者还在争论。
- 按其中一种换算，他的结果，
- 和今天测量的四万公里，相差不到百分之一。（开拍核：换算方式不同，结论不同）

**第八幕 · 一点运气**
- 不过，这里面也有运气。
- 赛伊尼其实不完全在太阳直射的那条线上，
- 也不正好在亚历山大的正南方。
- 两个误差，碰巧互相抵消了。
- 可他的方法，是完全正确的。

**结尾**
- 他没有离开过地面，
- 只用一根木棍、一个角度、一段距离，
- 就量出了整个世界。

**回顾**：井底的阳光 → 木棍的影子 → 亚历山大图书馆 → 贝塔 → 7.2 度 → 平行的光 → 乘以五十 → 二十五万斯塔德 → 不到百分之一 → 一点运气

## 值得记住（给用户）
- 弧长 s = Rθ（θ 用弧度）。**必记。**
- 地球周长约 4.0×10⁴ km，半径约 6.4×10³ km。**估算必备。**

## 查证结果（2026-10-23 网页核对）
**已核实**
- 他的前提：赛伊尼在北回归线上、在亚历山大正南方；两者都不精确（赛伊尼在北回归线以北约 1°、在亚历山大以东约 3°），两个误差恰好部分抵消。
- 斯塔德的长度有争议（160–210 米），直接影响结果。
- 按 180 米的斯塔德，有学者估算他的原始结果约 22.41 万斯塔德、约 40,338 公里，误差不到 1%；页面称其“极其接近现代测量”。
- 25 万斯塔德的数字来自克莱奥迈季斯等后世记载；罗马时代的资料改成 25.2 万、25.92 万。
- 现代值：赤道周长 40,075 公里，经线周长 40,008 公里。
