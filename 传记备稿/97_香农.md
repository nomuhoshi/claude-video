## 开拍简报（草案）
- 一句话主题：密歇根小镇长大的香农，小时候用农场的铁丝网，给半英里外的朋友家拉了一条电报线；他的偶像爱迪生是他的远房亲戚。21 岁时，他在麻省理工的硕士论文里证明：用开关电路可以实现逻辑运算——“真/假”就是“开/关”，这篇论文被称为“世纪最重要的硕士论文”，成了所有数字电路的起点。二战时他在贝尔实验室研究密码，和图灵喝过茶。1948 年，他发表《通信的数学理论》，第一次说清楚了“信息”是什么、怎么度量：单位是“比特”。他还会骑独轮车、抛球杂耍，造过会走迷宫的机械老鼠，和朋友做出了可穿戴计算机去轮盘赌桌上算概率。
- 观众起点：看过 96 图灵、49 冯·诺依曼、88 克劳修斯（熵）。
- 信息部分（不推导）：
  1. **开关就是逻辑**：两个开关串联 = “与”（都开灯才亮）；并联 = “或”（任一开灯就亮）。计算机里的一切运算，都是这样的开关组合。
  2. **比特**：抛一枚公平的硬币，结果是正是反，这个不确定性，就是 1 比特的信息。从 8 个等可能的选项里猜中一个，需要 3 个是/否问题 → 3 比特（**值得记**：N 个等可能结果的信息量 = log₂N 比特）。
  3. **信息熵** H = −Σ p log₂ p（**值得记**）：越出乎意料的消息，信息量越大；“明天太阳从东边升起”几乎没有信息。为什么也叫“熵”：形式和统计物理里的熵一样（回扣 88 克劳修斯、第 9 期玻尔兹曼）。
  4. **噪声里的通信**：只要传输速率不超过信道容量，就能用聪明的编码，让错误率任意小。信道容量 C = B·log₂(1 + S/N)（**值得记**，香农-哈特利公式）——今天的 Wi-Fi、5G、光纤都在逼近这个极限。
- 钩子：一个小盒子，上面只有一个开关。你把开关拨上去，盒盖打开，伸出一只机械手，把开关拨回去，然后缩回盒子里，盒盖关上。“这台机器唯一的功能，就是把自己关掉。设计它的人，是信息论之父。”（这只“最终机器 / 无用盒子”与香农的关联开拍核）
- 章节：密歇根佩托斯基出生、盖洛德长大 → 偶像爱迪生是远房亲戚 → 铁丝网电报 → 密歇根大学两个学士（电机、数学）→ 麻省理工：微分分析机 → 1937 年硕士论文：布尔代数 + 开关电路 → 博士（遗传学的数学 → 开拍核）→ 普林斯顿高等研究院短暂停留 → 二战：贝尔实验室，密码学，1943 年和图灵见面 → 1948《通信的数学理论》：比特、熵、信道容量 → “比特”一词（开拍核：图基）→ 为什么叫熵（开拍核：冯·诺依曼的建议）→ 1949 年密码学的数学理论 → 1950 年：会走迷宫的机械老鼠“忒修斯”、下棋程序的论文 → 独轮车、杂耍 → 和索普的可穿戴计算机 → 投资（巴伦周刊评价）→ 晚年阿尔茨海默病 → 2001 年 2 月 24 日去世 → 回顾。
- 不讲：编码定理的证明。
- 结尾：“你此刻看这个视频，每一秒都有几百万个比特穿过网线和空气——每一个比特，都是用他的单位来量的。”最后一句：“他让信息，第一次有了一个可以计算的单位。”
- 配乐：轻快（无用盒子钩子）→ Entropy（铁丝网电报、开关）→ Awakening（比特 = 高潮）→ 轻快（独轮车、杂耍、机械老鼠）→ 安静（晚年）→ 尾。
- 封面：一个由 0 和 1 组成的人像剪影在骑独轮车、抛三个球；钩子“比特”。
- 片尾剪影（第六季预告）：1945 年，一个从昆明西南联大毕业的中国青年，坐船去了英国 → “第六季：中国物理学家。”（第六季 B 档从 98 黄昆开始）

## 字幕稿

**开场**
- 一个小木盒，上面只有一个开关。
- 你把开关拨上去。
- 盒盖打开，伸出一只机械手，
- 把开关拨回去，又缩了回去。
- 盒盖关上。
- 这台机器唯一的功能，就是把自己关掉。
- 据说，这是信息论之父最喜欢的玩具之一。（开拍核）
- 他叫香农。

**章节 · 铁丝网**

**第一幕 · 密歇根小镇**
- 1916 年，香农出生在美国密歇根州，
- 在一个只有几千人的小镇长大。
- 他的偶像是爱迪生——后来才知道，爱迪生还是他的远房亲戚。

**第二幕 · 铁丝网电报**
- 小时候，他用农场里围牲口的铁丝网，
- 给半英里外的朋友家，拉了一条电报线。
- 两个孩子用摩尔斯电码，互相发消息。

**章节 · 开关**

**第三幕 · 麻省理工**
- 他在密歇根大学拿了电机工程和数学两个学位，
- 然后去麻省理工读研究生，
- 帮忙操作一台巨大的机械计算机，
- 里面有上百个继电器开关。

**第四幕 · 开和关**
- 他想起了大学里学过的一门冷门数学：布尔代数，
- 只处理“真”和“假”。
- 他发现：开关的“开”和“关”，正好对应“真”和“假”。
- 两个开关串联：都开，灯才亮，这是“与”；
- 两个开关并联：开一个，灯就亮，这是“或”。
- 用开关电路，可以做任何逻辑运算。
- 1937 年，二十一岁的他写成了硕士论文。
- 后来有人说，这是“这个世纪最重要的硕士论文”。
- 今天所有的数字电路，都从这里开始。

**章节 · 比特**

**第五幕 · 战争和密码**
- 二战期间，香农在贝尔实验室研究密码。
- 1943 年，英国的图灵来美国访问，
- 两个人在实验室的餐厅里喝茶聊天，
- 聊机器能不能思考。

**第六幕 · 信息是什么**
- 战争结束后，他想回答一个问题：
- 信息，到底是什么？能不能量一量有多少？

**第七幕 · 一枚硬币**
- 1948 年，他发表了《通信的数学理论》。
- 他说：信息，就是消除不确定性。
- 抛一枚硬币，正面还是反面，
- 告诉你结果，就给了你 1 个单位的信息。
- 他把这个单位叫作“比特”。
- 从 8 个可能里猜中一个，需要问 3 个“是不是”，就是 3 比特。

**第八幕 · 意外的消息**
- 越是出乎意料的消息，信息量越大。
- “明天太阳从东边升起”，几乎没有信息；
- “明天下雪”，在夏天就是很大的信息。
- 他写出了计算信息量的公式，
- 发现它和物理学里“熵”的公式长得一模一样，
- 于是，他也把它叫作“熵”。

**第九幕 · 噪声**
- 电话线、无线电里都有噪声，会把信息弄错。
- 香农证明：
- 只要传送的速度不超过某个极限，
- 就一定能找到一种编码方法，让错误少到几乎没有。
- 今天的手机、Wi-Fi、光纤网络，
- 都在想办法逼近他算出的这个极限。

**章节 · 玩**

**第十幕 · 独轮车和杂耍**
- 香农是个爱玩的天才。
- 他常常骑着独轮车，在贝尔实验室的走廊里穿行，
- 还会一边骑，一边抛球杂耍。

**第十一幕 · 走迷宫的老鼠**
- 1950 年，他造了一只机械老鼠，叫“忒修斯”。
- 第一次走迷宫，它到处乱撞；
- 第二次，它就记住了路，直接走到终点。
- 这是最早会“学习”的机器之一。
- 同一年，他还写了一篇论文，讨论怎样让计算机下国际象棋。

**第十二幕 · 轮盘赌**
- 他还和数学家朋友索普一起，
- 做了一台可以藏在鞋子里的小计算机，
- 用来估算赌场轮盘上的小球会落在哪里。
- 这是最早的可穿戴计算机之一。

**第十三幕 · 晚年**
- 晚年，他得了阿尔茨海默病，
- 渐渐记不起自己创造的那些东西。
- 2001 年 2 月，香农去世，八十四岁。

**结尾**
- 你此刻看这个视频，
- 每一秒，都有几百万个比特穿过网线和空气。
- 每一个比特，都是用他的单位来量的。
- 他让信息，第一次有了一个可以计算的单位。

**回顾**：会关掉自己的盒子 → 密歇根小镇 → 铁丝网电报 → 继电器开关 → 布尔代数 → 串联是与、并联是或 → 最重要的硕士论文 → 和图灵喝茶 → 信息是什么 → 一枚硬币 → 比特 → 意外的消息 → 熵 → 噪声和极限 → 独轮车 → 走迷宫的老鼠 → 轮盘赌

## 值得记住（给用户）

- 信息熵 H = −Σ pᵢ log₂ pᵢ。**值得记。**
