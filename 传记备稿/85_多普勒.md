# 85 多普勒（Christian Doppler，1803–1853）

## 开拍简报（草案）
- 一句话主题：萨尔茨堡石匠家的儿子多普勒，身体太弱干不了家里的手艺，学了数学和物理；他找不到合适的工作，一度准备移民美国，最后在布拉格得到了教职。1842 年，他在一篇关于双星颜色的论文里提出：波源和观察者相对运动时，接收到的频率会变——靠近时变高，远离时变低。他想用这个解释星星的颜色（这一点其实不对，星星跑得没那么快），可这个效应本身是对的：三年后，荷兰的拜斯·巴洛特在铁路上用乐手做实验验证了它。他后来在维也纳大学当实验物理研究所所长，学生里有一位修道士叫孟德尔。他 49 岁死于肺病。今天，从测速雷达、医院的彩超，到哈勃发现宇宙膨胀，到处都是多普勒效应。
- 观众起点：零（高中选修：多普勒效应）。
- 物理部分（不推导）：
  1. **为什么会变调**：一辆鸣笛的车开过来，每发出一个波峰，车就往前走了一点，后面的波峰离前面的更近——你耳朵收到的波峰更密，频率更高，声音更尖；开走时正好相反。
  2. **公式** f' = f(v + v_r)/(v − v_s)（接收者靠近取 +v_r，波源靠近取 −v_s）（**值得记**）。例：一辆车以 34 m/s（约每小时 120 公里）开过，音调升高约 11%（开拍核计算：340/(340−34) ≈ 1.11）。
  3. **光的多普勒**：远离的星系光会变红（红移），靠近的变蓝（蓝移）——1848 年斐索对光做了同样的推导；后来被用来测量恒星、星系的速度（回扣 57 哈勃）。
  4. 应用：交警测速雷达、彩色多普勒超声看血流方向、天气雷达。
- 钩子：一辆救护车鸣着笛开过来，声音尖锐，从你身边驶过的那一刻，声音一下子变低了。“同一个喇叭，为什么开过来和开过去的声音不一样？”
- 章节：萨尔茨堡（石匠世家的第二个儿子，体弱，父亲让他学经商）→ 维也纳理工学院、维也纳大学学数学和物理 → 找不到教职，1835 年准备移民美国 → 最后一刻，布拉格给了他职位 → 1837 年副教授、1841 年正教授 → 1842 年：在布拉格的皇家波希米亚科学学会演讲、发表《论双星的彩色光》→ 他想解释星星的颜色（这点不对）→ 1845 年拜斯·巴洛特在荷兰铁路上的实验 → 1848 年斐索：光 → 1847 年去塞尔梅克巴尼亚的矿业林业学院 → 1848 年匈牙利革命，次年逃回维也纳 → 1850 年维也纳大学实验物理研究所所长，学生孟德尔（后来的遗传学之父）→ 肺病 → 1853 年 3 月 17 日在威尼斯去世，49 岁 → 回顾。
- 不讲：相对论多普勒效应（一句话）。
- 结尾：“哈勃就是用这个效应，发现了星系在离我们远去。”最后一句：“一个差点去了美国的数学老师，让我们从声音的变化里，听出了速度。”
- 配乐：救护车声（钩子，音量控制）→ Entropy（萨尔茨堡、维也纳）→ 安静（求职受挫）→ Awakening（波峰变密的动画 = 高潮）→ 火车 + 小号（拜斯·巴洛特）→ 宇宙感（红移）→ 尾。
- 封面：一辆救护车，前面的声波圈挤得很密，后面的稀疏；钩子“声音为什么会变调”。

## 字幕稿

**开场**
- 一辆救护车鸣着笛开过来。
- 声音又尖又急。
- 就在它从你身边驶过的那一刻，
- 声音一下子变低了。
- 同一个喇叭，为什么开过来和开过去，声音不一样？
- 第一个解释这件事的人，叫多普勒。

**章节 · 石匠的儿子**

**第一幕 · 萨尔茨堡**
- 1803 年，多普勒出生在奥地利的萨尔茨堡，
- 家里世代都是石匠。
- 可他从小体弱，干不了石匠的重活，
- 父亲让他去学经商。
- 他却喜欢数学。

**第二幕 · 维也纳**
- 他到维也纳，学了数学和物理，
- 成绩很好，却一直找不到正式的教职。
- 1835 年，他甚至打算放弃，
- 移民去美国。

**第三幕 · 布拉格**
- 就在准备出发的时候，
- 布拉格的一所理工学院给了他一个教职。
- 他留了下来。
- 几年后，他成了正教授。

**章节 · 变调**

**第四幕 · 1842**
- 1842 年，多普勒在布拉格的一次学术会议上，
- 发表了一篇论文，题目是：《论双星的彩色光》。
- 他提出：
- 当发出波的东西和接收的人在相对运动时，
- 接收到的频率会变化。
- 靠近时，变高；远离时，变低。

**第五幕 · 为什么**
- 想象一辆鸣笛的车，每一秒发出很多个声波的波峰。
- 车在往前开，
- 每发出一个波峰，车就往前挪了一点，
- 下一个波峰，就离前一个更近。
- 你的耳朵收到的波峰更密，频率更高，声音就更尖。
- 车开走时，波峰被拉稀，声音就变低。

**第六幕 · 星星的颜色**
- 多普勒本来想用这个效应，解释为什么有些星星偏红、有些偏蓝。
- 这一点，他其实想错了：
- 星星的颜色主要由温度决定，
- 普通恒星跑得没有那么快，颜色变不了那么多。
- 可他提出的这个效应本身，是对的。

**章节 · 火车上的乐手**

**第七幕 · 1845**
- 1845 年，荷兰气象学家拜斯·巴洛特，
- 在荷兰的铁路上做了一个实验：
- 让乐手坐在行驶的火车上吹奏一个固定的音，
- 站台旁，让几位耳朵很灵的音乐家来听。（开拍核细节）
- 火车开来时，音调变高；开走时，音调变低。
- 多普勒是对的。

**第八幕 · 光也一样**
- 1848 年，法国物理学家斐索指出：
- 光也有同样的效应。
- 远离我们的星，光会往红色那边偏；
- 靠近我们的，往蓝色那边偏。
- 七十多年后，哈勃就是用这一点，
- 发现了遥远的星系都在离我们远去。

**章节 · 维也纳**

**第九幕 · 逃难**
- 1847 年，多普勒到了匈牙利北部的一所矿业学院。
- 第二年，匈牙利爆发革命，
- 他的研究被打断，
- 1849 年，他逃回了维也纳。

**第十幕 · 孟德尔**
- 1850 年，他成为维也纳大学实验物理研究所的所长。
- 他教过一个来自修道院的学生，
- 叫孟德尔。
- 后来，孟德尔在修道院的花园里种豌豆，发现了遗传的规律。

**第十一幕 · 威尼斯**
- 多普勒的身体一直不好，
- 后来得了严重的肺病。
- 他去意大利威尼斯养病，
- 1853 年 3 月，在那里去世，四十九岁。

**结尾**
- 今天，交警的测速雷达、医院的彩色超声、天气预报的雷达，
- 用的都是多普勒效应。
- 一个差点去了美国的数学老师，
- 让我们从声音的变化里，听出了速度。

**回顾**：救护车变调 → 石匠的儿子 → 体弱 → 差点移民美国 → 布拉格 → 1842 → 靠近变高、远离变低 → 波峰变密 → 星星的颜色（想错了）→ 火车上的乐手 → 光也一样 → 红移 → 逃难 → 孟德尔 → 威尼斯

**片尾剪影（按内容顺序）**
- 19 世纪的曼彻斯特，一家酿酒厂的少东家，在地下室里用一个桨叶在水里不停地搅。
- “下一期：搅出来的热。”

## 值得记住（给用户）
- 多普勒公式（声波）：f' = f·(v ± v_r)/(v ∓ v_s)，“靠近频率升高”。**值得记。**
- 光的多普勒（低速）：Δλ/λ ≈ v/c。

## 查证结果（2026-10-23 网页核对）
**已核实**
- 1803 年 11 月 29 日生于萨尔茨堡；石匠世家（第三代）的次子；体弱，父亲让他从商。
- 1822 年维也纳理工学院，后在维也纳大学等学数学物理。
- 1835 年决定移民美国，因布拉格的教职邀请留下；1837 年副教授、1841 年正教授（布拉格理工学院）。
- 1842 年在皇家波希米亚科学学会演讲并发表《论双星的彩色光》，提出多普勒效应。
- 1847 年到塞尔梅克巴尼亚矿业林业学院；1848 年匈牙利革命中断研究，1849 年逃回维也纳。
- 1850 年任维也纳大学实验物理研究所所长，与翁格一起影响了孟德尔。
- 1853 年 3 月 17 日在威尼斯死于肺病，49 岁；葬圣米凯莱公墓。
- 拜斯·巴洛特 1845 年验证声波的多普勒效应（论文题为《荷兰铁路上的声学实验》）；斐索 1848 年独立提出光的同一效应（Wikipedia: Doppler effect）。
