# 传记备稿（科学家传记系列 · 片单与逐期脚本草稿）

2026-10-22 起备稿。每一期一份 `NN_名字.md`，内容固定为：

1. **标题候选**：格式“名字｜称号｜科学家传记系列”，每个都标字数（≤20）；另给一个悬念型主标题（视频内大字用）
2. **开拍简报**：同 SOP 的 grill-me-video 简报字段（主题、钩子、观众起点、章节、不讲、结尾、配乐、封面）
3. **字幕稿**：按“章节卡 + 幕”分好，每行一句字幕（≤约 20 字），可以直接改写成 `script_xx.py` 的 `SC` 表
4. **已查证 / 写“据说” / 不写**：查证结论和出处
5. **来源**：成片来源页用
6. **片尾剪影**：下一期人物的剪影预告句

> 开拍时仍按 SOP：先 grill（一次一问，带推荐答案），简报确认后再做画面。备稿只是把“查证 + 写稿”提前做好，开拍时可以整段改。
> 人名在字幕说出之前不上屏；晚年情绪必须有出处（已在各稿“已查证”里标出）。

### 为什么这样排

- 6–8 是“光与以太”线：赫兹证明电磁波 → 迈克尔逊找以太找不到 → 洛伦兹给出变换 → 爱因斯坦。
- 9–11 是“热与统计”线：玻尔兹曼的统计 + 基尔霍夫的黑体问题 = 普朗克的量子。
- 12 爱因斯坦把三条线（光电效应、光速不变、量子）一起接住；13 布朗与佩兰是他 1905 年第三条线（布朗运动）的续集，也回扣玻尔兹曼。
- 14–18 是“打开原子”：射线 → 放射性 → 电子 → 原子核 → 电子电荷。
- 19–21 是旧量子论；22–28 是量子力学的诞生（1924–1928）；29 收尾。
- 配角（不单独成期，放进相邻期里讲）：约尔当（26）、埃伦费斯特（29）、塞曼（8）、斯特藩（9）、本生（10）、维恩与瑞利（11）、盖革与马斯登（17）、斯特恩与格拉赫（20）、戴维孙与革末（22）、费米（24 中微子命名、23 费米子对照）。
- 费米、迈特纳、冯·诺依曼、费曼、贝尔已排进下面的第二季（30–41）。
