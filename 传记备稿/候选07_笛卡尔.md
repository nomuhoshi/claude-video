## 开拍简报（草案）
- 一句话主题：法国人笛卡尔，母亲在他一岁时去世；他在耶稣会学校读书，学了法律，却跑去荷兰参军，在军营里遇到了一位业余科学家，开始思考数学和自然。1619 年冬天，他在一间烧着火炉的小屋里做了几个梦，决心用一种全新的方法重建所有知识。他在荷兰住了二十年，1637 年出版《方法论》，附录《几何》把几何和代数连在一起——这就是坐标系的起点；同一本书里，他解释了光的折射，算出了彩虹为什么总出现在约 42 度的方向。他说出了“我思故我在”，也写下了最早的惯性定律之一。1649 年他应瑞典女王之邀去斯德哥尔摩，每天清晨五点给女王上课，第二年冬天因肺炎去世。
- 观众起点：无需前置；看过 5 伽利略、3 牛顿更好。
- 物理部分（不推导）：
  1. **坐标**：用两个数 (x, y) 就能标出平面上任何一个点；一条直线、一个圆都能写成方程——几何问题变成了代数问题。牛顿的运动方程能写出来，前提就是这套语言。
  2. **惯性**：笛卡尔明确写出，物体不受干扰时会沿直线一直运动下去（伽利略认为是“圆周惯性”→ 开拍核措辞）。后来成为牛顿第一定律。
  3. **折射**：光从空气进入水，方向会偏折（**值得记**：n₁ sinθ₁ = n₂ sinθ₂，斯涅尔-笛卡尔定律）。
  4. **彩虹的 42 度**：阳光进入一颗水滴，折射一次、在背面反射一次、出来再折射一次。笛卡尔一条光线一条光线地计算，发现出射光会大量集中在和入射方向成约 42° 的方向上——所以彩虹总是一个以你影子的头部为中心、半径约 42° 的圆弧。不同颜色折射得略有不同，于是分成了七彩（颜色分离这一步要等牛顿 → 开拍核）。
- 钩子：雨后，背对太阳，彩虹总出现在同一个高度。“如果你伸直手臂，彩虹到你影子头部的角度，永远是大约 42 度。为什么？”
- 章节：拉艾出生（1596）→ 一岁丧母 → 拉弗莱什耶稣会学校 → 普瓦捷大学法律（1616）→ 1618 年加入拿骚的莫里斯的军队 → 在布雷达遇见贝克曼，开始研究数学和物理 → 1619 年 11 月 10–11 日夜，诺伊堡一间烧火炉的屋子里的三个梦 → 定居荷兰二十年 → 1633 年伽利略被判，他压下了自己的《论世界》→ 1637 年《方法论》：《屈光学》《气象学》《几何》三篇附录 → 坐标、折射、彩虹 → “我思故我在” → 1644 年《哲学原理》：运动定律、漩涡理论 → 1649 年去瑞典 → 女王每天清晨五点的课 → 1650 年 2 月 11 日因肺炎去世 → 回顾。
- 不讲：形而上学和身心二元论的哲学论证（一句话带过）；“看苍蝇想到坐标”的说法（无可靠出处，不写）。
- 结尾：“今天，每一张函数图像、每一张地图上的经纬线、每一个屏幕上的像素位置，背后都是那两个数：x 和 y。”
- 配乐：巴洛克（钩子）→ 安静（火炉边的梦）→ Entropy（荷兰）→ Awakening（42 度 = 高潮）→ 冷色（斯德哥尔摩的清晨）→ 尾。

## 字幕稿

**开场**
- 雨后，背对着太阳，
- 你会发现，彩虹总是出现在差不多的高度。
- 从你影子的头部到彩虹，
- 角度永远是大约 42 度。
- 第一个算出这个数的人，
- 也给了我们 x 和 y。
- 他叫笛卡尔。

**章节 · 火炉边**

**第一幕 · 拉艾**
- 1596 年，笛卡尔出生在法国的拉艾。
- 第二年，他的母亲就去世了。
- 他在一所耶稣会学校读书，后来在普瓦捷大学学了法律。

**第二幕 · 军营**
- 1618 年，他没去当律师，
- 而是跑到荷兰，加入了拿骚的莫里斯的军队。
- 在那里，他遇到了一位叫贝克曼的学者，
- 两人一起讨论数学和物理，
- 笛卡尔从此迷上了用数学去理解自然。

**第三幕 · 三个梦**
- 1619 年 11 月，在德国的诺伊堡，
- 他待在一间烧着火炉的小屋里，
- 一整天都在思考。
- 那天夜里，他做了三个梦。
- 醒来后，他下定决心：
- 要用一种全新的方法，从头建立所有的知识。

**章节 · 方法**

**第四幕 · 荷兰二十年**
- 后来，他在荷兰住了二十年。
- 1633 年，他听说伽利略被教会审判，
- 就把自己已经写好的一本讲宇宙的书，压了下来。

**第五幕 · 方法论**
- 1637 年，他出版了《方法论》。
- 书的后面，有三篇附录：讲光学的、讲天气的，和讲几何的。

**第六幕 · x 和 y**
- 在讲几何的那一篇里，他做了一件事：
- 把几何和代数，连在了一起。
- 平面上的一个点，可以用两个数来标出；
- 一条直线、一个圆，都可以写成一个方程。
- 画图的问题，变成了算数的问题。
- 后来，牛顿就是用这种语言，写下了运动的规律。

**章节 · 42 度**

**第七幕 · 折射**
- 在讲光学的附录里，他写下了光的折射定律：
- 光从空气进入水，方向会偏折，
- 偏折多少，可以精确地算出来。

**第八幕 · 一颗水滴**
- 在讲天气的附录里，他问：彩虹是怎么来的？
- 他想象一颗水滴：
- 阳光射进去，折射一次；
- 在水滴的背面，反射一次；
- 射出来，再折射一次。

**第九幕 · 一条一条地算**
- 他一条光线、一条光线地计算，
- 发现：射出来的光，
- 会大量地挤在和入射方向成大约 42 度的方向上。
- 所以，彩虹总是一个以你影子的头部为中心、
- 张开大约 42 度的圆弧。

**第十幕 · 惯性**
- 1644 年，他在《哲学原理》里写道：
- 一个物体如果不受干扰，会沿着直线，一直运动下去。
- 几十年后，这成了牛顿第一定律。

**章节 · 斯德哥尔摩**

**第十一幕 · 我思故我在**
- 笛卡尔还是一位哲学家。
- 他怀疑一切，
- 最后发现，只有一件事无法怀疑：
- 我正在思考。
- “我思故我在。”

**第十二幕 · 清晨五点**
- 1649 年，瑞典女王克里斯蒂娜请他去斯德哥尔摩。
- 女王要求，每天清晨五点上课。
- 那是北欧最冷的冬天。
- 1650 年 2 月，笛卡尔因肺炎去世，五十三岁。

**结尾**
- 今天，每一张函数图像，
- 每一张地图上的经纬线，
- 每一个屏幕上像素的位置，
- 背后都是那两个数：x 和 y。

**回顾**：42 度 → 拉艾 → 军营 → 贝克曼 → 火炉边的三个梦 → 荷兰二十年 → 压下的书 → 方法论 → x 和 y → 折射 → 一颗水滴 → 42 度 → 惯性 → 我思故我在 → 清晨五点
