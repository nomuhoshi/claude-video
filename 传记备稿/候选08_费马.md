## 开拍简报（草案）
- 一句话主题：费马白天是法国图卢兹议会的法官，数学只是业余爱好——可这个“业余爱好者”和笛卡尔各自独立地发明了解析几何，用一种叫“近似相等”的方法找到曲线的最高点、最低点和切线，走在微积分的前面；他和帕斯卡通信，一起奠定了概率论；他发现，光在两点之间走的，总是花时间最少的那条路——由此可以推出折射定律。他在一本古希腊数学书的页边写下一句话：我有一个绝妙的证明，可惜这里空白太小，写不下。这道题，人类花了三百多年，直到 1994 年才由怀尔斯证明。
- 观众起点：无需前置；看过候选 07 笛卡尔、68 帕斯卡更好。
- 物理部分（不推导）：
  1. **救生员问题**：救生员在沙滩上，要去救水里的人。沙滩上跑得快，水里游得慢。直线最短，却不是最快；最快的路线是：在沙滩上多跑一点，在水里少游一点——路线在岸边“折”了一下。
  2. **费马原理**：光也一样。光在空气里快、在水里慢，它从 A 到 B 走的，正好是用时最少的那条路——所以光进入水时会“折”一下。从这条原理，能推出折射定律（**值得记**：sinθ₁/v₁ = sinθ₂/v₂，等价于 n₁ sinθ₁ = n₂ sinθ₂）。
  3. **光怎么“知道”**：光好像能“预先知道”哪条路最快——这个问题后来引出了“最小作用量原理”，再到费曼的路径积分（回扣 38 费曼，一句话）。
  4. **费马大定理**（数学，一句话）：xⁿ + yⁿ = zⁿ，当 n 大于 2 时，没有正整数解。n = 2 时有解（3² + 4² = 5²，勾股定理）。
- 钩子：一本旧书的页边，一行小字：“我发现了一个真正绝妙的证明，可惜这里空白太小，写不下。”“为了这几个字，全世界的数学家找了三百五十多年。”
- 章节：博蒙德洛马涅出生（出生年份有不确定 → 1601）→ 奥尔良大学法律 → 1630 年起任图卢兹议会顾问（法官）→ 业余数学，靠写信交流 → 解析几何（与笛卡尔独立）→ “近似相等”：找最大值、最小值、切线（微积分的前驱）→ 1654 年与帕斯卡通信：赌局中断后赌注怎么分 → 概率论（回扣 68）→ 光走最快的路：费马原理 → 与笛卡尔对折射的争论（开拍核）→ 费马小定理 → 丢番图《算术》页边的批注 → 1665 年 1 月在卡斯特尔去世 → 批注被公开（开拍核：儿子出版）→ 三百多年无人能证 → 1994 年怀尔斯 → 回顾。
- 不讲：怀尔斯证明的内容（一句话：用到了费马死后几百年才发展出来的数学）。
- 结尾：“一个业余爱好者，留下了一条光的原理，和一道让人类追了三百多年的题。”最后一句：“他说空白太小。今天的数学家大多相信，他当时并没有一个真正正确的证明。”（开拍核措辞）
- 配乐：巴洛克（页边钩子）→ 安静（法官的白天）→ Entropy（通信）→ Awakening（光走最快的路 = 高潮）→ 神秘（三百年）→ 尾。

## 字幕稿

**开场**
- 一本古希腊数学书的页边，
- 有一行小字：
- “我发现了一个真正绝妙的证明，
- 可惜这里空白太小，写不下。”
- 为了这几个字，
- 全世界的数学家，找了三百五十多年。
- 写下它的人，叫费马。

**章节 · 业余**

**第一幕 · 法官**
- 费马大约 1601 年出生在法国南部，
- 学的是法律，
- 1630 年起，在图卢兹的议会担任法官。
- 数学，只是他的业余爱好。

**第二幕 · 写信**
- 他很少发表论文，
- 也几乎不离开图卢兹。
- 他和别人交流数学，靠的是写信。

**第三幕 · 微积分之前**
- 他和笛卡尔各自独立地，
- 想到了用代数来研究几何。
- 他还发明了一种方法，
- 能找到一条曲线的最高点、最低点，和它的切线。
- 这已经非常接近后来的微积分了。

**第四幕 · 赌局**
- 1654 年，他和帕斯卡通信，讨论一个问题：
- 一场赌局打到一半被迫中断，赌注该怎么分？
- 两人的这些信，奠定了概率论的基础。

**章节 · 光走最快的路**

**第五幕 · 救生员**
- 想象一位救生员，在沙滩上，
- 要去救水里的一个人。
- 他在沙滩上跑得快，在水里游得慢。
- 直线最短，可不是最快。
- 最快的路线是：在沙滩上多跑一点，在水里少游一点，
- 路线在岸边，“折”了一下。

**第六幕 · 光也一样**
- 费马说，光也是这样。
- 光在空气里快，在水里慢。
- 从一点到另一点，光走的，
- 正好是花时间最少的那条路。
- 所以，光射进水里，会折一下。
- 从这条原理，可以推出光的折射定律。
- 它后来被叫作“费马原理”。

**第七幕 · 光怎么知道**
- 可是，光怎么“知道”哪条路最快？
- 这个奇怪的问题，后来引出了物理学里最深刻的思想之一：
- 自然界，似乎总在“挑”一条最省的路。

**章节 · 页边**

**第八幕 · 一行小字**
- 费马读一本古希腊数学书时，
- 在页边写下了一个结论：
- x 的 n 次方加 y 的 n 次方，等于 z 的 n 次方，
- 当 n 大于 2 时，找不到正整数解。
- n 等于 2 时，是有解的：3 的平方加 4 的平方，等于 5 的平方。
- 可 n 等于 3、4、5……就不行了。
- 他写道：我有一个绝妙的证明，可惜这里空白太小，写不下。

**第九幕 · 三百多年**
- 1665 年 1 月，费马去世了。
- 那行小字被公开之后，
- 一代又一代的数学家试图证明它，都失败了。
- 直到 1994 年，英国数学家怀尔斯，
- 用费马死后几百年才发展出来的数学，终于证明了它。

**结尾**
- 一个业余的数学爱好者，
- 留下了一条光的原理，
- 和一道让人类追了三百多年的题。
- 他说空白太小。
- 今天的数学家大多相信，
- 他当时并没有一个真正正确的证明。

**回顾**：页边的小字 → 图卢兹的法官 → 写信 → 微积分之前 → 中断的赌局 → 救生员 → 光走最快的路 → 光怎么知道 → xⁿ + yⁿ = zⁿ → 三百多年 → 怀尔斯

## 值得记住（给用户）
- 费马原理：光沿用时最短的路径传播。由它可推出 sinθ₁/v₁ = sinθ₂/v₂。**这个结论值得记，推导不必做。**
- 勾股数 3、4、5。

## 查证结果（2026-10-23 网页核对）
**已核实**
- 出生于博蒙德洛马涅，页面写 1601 年（出生日期有不确定）；奥尔良大学学习。
- 1630 年起任图卢兹议会顾问；1665 年 1 月在卡斯特尔去世。
- “近似相等”法求极大极小值和切线，等价于微分学。
- 费马小定理；二平方和定理。
- 在丢番图《算术》的页边写道已有证明，原话大意：“我有一个真正绝妙的证明，这页边太窄写不下。”怀尔斯 1994 年证明，用到费马死后才发展出的技术。
- 1654 年与帕斯卡通信，奠定概率论基础。
- 提出光在两点之间走用时最短的路径（费马原理）。

**写“据说”或开拍再核**
- 页边批注约写于 1637 年、1670 年由儿子塞缪尔出版：页面未写，字幕只写“被公开之后”。
- 费马原理提出于 1662 年：页面未写，字幕没写年份。
- 与笛卡尔关于折射的争论：来自已有知识，开拍核，字幕没写。
- “三百五十多年”：按 1637 → 1994 推算约 357 年（依赖 1637 年这个时间），开拍核；也可改成“三百多年”。
- 怀尔斯 1994 年宣布、1995 年发表：页面写 1994 年证明，开拍核措辞。
- “数学家大多相信他没有正确的证明”：常见看法，开拍核措辞。
