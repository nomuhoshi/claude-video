## 开拍简报（草案）
- 一句话主题：俄亥俄州出生的爱迪生，几乎没上过正规学校，靠母亲在家教和自己读书；少年时在火车上卖报纸，听力逐渐变差；后来当电报员。他把发明变成了一门生意：在新泽西的门洛帕克建了一座“发明工厂”，一群人分工合作，专门做发明。1877 年他发明了留声机；1879 年他做出了能连续点亮很久的碳丝白炽灯——灯泡不是他第一个发明的，但他做出了实用的灯泡，还建起了发电站、电线、电表组成的一整套供电系统。他坚持直流电，和主张交流电的西屋、特斯拉打了一场“电流之战”，最后交流电赢了。他一生拿到一千多项美国专利。
- 观众起点：看过 91 特斯拉更好。
- 物理部分（不推导）：
  1. **灯丝为什么会亮**：电流通过灯丝，灯丝发热，热到两千多度就会发光（回扣 11 普朗克：热的物体会发光）。
  2. **为什么要抽真空**：空气里有氧气，灯丝一热就烧掉了。抽成真空，灯丝才能亮很久。
  3. **为什么要高电阻的灯丝**：很多盏灯并联在同一条线路上，每盏灯的电压一样。灯丝电阻大，每盏灯需要的电流就小，输电线上的电流也小，线上损失的能量就少（**值得记**：P = UI；线路损耗 P损 = I²R）。这是爱迪生选材料时最关键的物理考虑之一（开拍核措辞）。
  4. **电流之战的物理**：输电线上的损耗和电流的平方成正比。交流电可以用变压器把电压升得很高、电流降得很小，送到远方再降压——损耗小得多。直流电当时做不到这一点，只能就近发电（回扣 91 特斯拉；**值得记**：变压器 U₁/U₂ = n₁/n₂）。
  5. 爱迪生效应（一句话）：他在灯泡里发现，电流能从热灯丝“飞”过真空——后来成了电子管的基础（开拍核）。
- 钩子：一个灯泡亮起来。“灯泡不是爱迪生第一个发明的。在他之前，已经有二十多个人做过各种电灯（开拍核）。那他到底做了什么？”
- 章节：俄亥俄州米兰出生（1847）→ 搬到密歇根 → 在学校只待了几个月，母亲在家教他 → 火车上卖报纸，在行李车里做化学实验 → 听力逐渐变差 → 救了站长的孩子，学会发电报（开拍核）→ 电报员 → 第一项专利：投票计数器（没人买 → 教训：只发明有人要的东西）→ 四路电报 → 1876 年门洛帕克“发明工厂” → 1877 年留声机：“玛丽有只小羊羔” → 1879 年碳丝灯泡，试了几千种材料 → 1882 年纽约珍珠街电站 → 电流之战 → 交流电胜出 → 电影摄影机、电池 → 一千多项专利 → “天才是百分之一的灵感加百分之九十九的汗水”（出处开拍核）→ 1931 年 10 月去世 → 回顾。
- 不讲：电流之战中有争议的宣传手段（大象事件等，他是否直接参与有争议 → 不写）；对他人格的评价。
- 结尾：“他让发明从一个人的灵光一闪，变成了一群人的日常工作。今天每一座研发中心，都有一点门洛帕克的影子。”
- 配乐：轻快（灯泡钩子）→ 怀旧（火车）→ 工业感（发明工厂）→ Awakening（灯泡亮起 = 高潮）→ 紧张（电流之战）→ 尾。
- 封面：一个发着暖光的碳丝灯泡，背景是门洛帕克实验室；钩子“发明工厂”。

## 字幕稿

**开场**
- 一个灯泡，亮了。
- 灯泡，不是爱迪生第一个发明的。
- 在他之前，已经有很多人做过各种电灯。
- 那他到底做了什么？
- 为什么全世界都记住了他？

**章节 · 报童**

**第一幕 · 米兰**
- 1847 年，托马斯·爱迪生出生在美国俄亥俄州的米兰。
- 他只在学校里待了几个月，
- 剩下的，是母亲在家里教他，
- 和他自己读书。

**第二幕 · 火车**
- 十几岁，他在火车上卖报纸和糖果，
- 还在行李车厢里做化学实验。
- 那几年，他的听力越来越差。

**第三幕 · 电报**
- 后来，他学会了发电报，
- 成了一名电报员。
- 他的第一项专利，是一台给议会用的投票计数器。
- 没人买。
- 他从此记住：只发明人们需要的东西。

**章节 · 发明工厂**

**第四幕 · 门洛帕克**
- 1876 年，他在新泽西的门洛帕克，建了一座实验室。
- 这里有机械师、化学家、玻璃工，
- 一群人分工合作，专门做发明。
- 人们叫它“发明工厂”。

**第五幕 · 留声机**
- 1877 年，他发明了留声机。
- 他对着机器念了一句儿歌：
- “玛丽有只小羊羔。”
- 机器把他的声音，放了出来。

**章节 · 灯泡**

**第六幕 · 为什么会亮**
- 电流通过一根细丝，细丝发热，
- 热到两千多度，就会发光。
- 难的是：怎样让它一直亮着，不烧断？

**第七幕 · 真空**
- 空气里有氧气，灯丝一热，就烧掉了。
- 所以，要把灯泡里的空气抽干净。

**第八幕 · 几千种材料**
- 灯丝用什么做？
- 他的团队试了几千种材料。
- 1879 年，他们用一根碳化的棉线，
- 让灯泡连续亮了十几个小时。（开拍核）

**第九幕 · 不只是灯泡**
- 可一个灯泡，没有用。
- 爱迪生要的，是让一整座城市亮起来：
- 发电站、电线、开关、电表、保险丝，一整套系统。
- 1882 年，纽约珍珠街电站开始供电。

**章节 · 电流之战**

**第十幕 · 直流还是交流**
- 爱迪生的系统，用的是直流电。
- 西屋公司和特斯拉，推广的是交流电。
- 输电线上损失的能量，和电流的平方成正比。
- 交流电可以用变压器把电压升高、电流降低，
- 送到很远的地方，损失也很小。
- 直流电当时做不到，只能在附近发电。

**第十一幕 · 结局**
- 两边打了一场激烈的“电流之战”。
- 最后，交流电赢了。
- 今天，你家插座里的，就是交流电。

**第十二幕 · 一千多项**
- 爱迪生一生在美国拿到了一千多项专利。
- 1931 年 10 月，他在新泽西去世，八十四岁。

**结尾**
- 他让发明，从一个人的灵光一闪，
- 变成了一群人的日常工作。
- 今天的每一座研发中心，
- 都有一点门洛帕克的影子。

**回顾**：灯泡不是他第一个发明的 → 米兰 → 母亲教的 → 火车上的报童 → 电报员 → 没人要的发明 → 门洛帕克 → 留声机 → 为什么会亮 → 真空 → 几千种材料 → 一整套系统 → 直流还是交流 → 电流的平方 → 一千多项专利

## 值得记住（给用户）
- 电功率 P = UI = I²R = U²/R。**必记。**
- 输电损耗 P损 = I²R线；升压 n 倍，电流降为 1/n，损耗降为 1/n²。**必记。**
- 理想变压器 U₁/U₂ = n₁/n₂。**必记。**
