## 开拍简报（草案）
- 一句话主题：同一年出生在巴黎的两个法国人，曾经是合作伙伴，一起拍下了最早的太阳照片之一；后来成了竞争对手，比赛谁先在地面上测出光速。1849 年，菲佐让一束光穿过一个高速旋转的齿轮，射到八公里外的镜子上再反射回来，第一次在地面上测出了光速。傅科改用旋转的镜子，不但测出了光速，还证明了光在水里比在空气里慢——这正好支持了光是波（回扣 79 托马斯·杨、80 菲涅耳）。1851 年，傅科在巴黎先贤祠的穹顶下挂起一只 67 米长的大摆，观众亲眼看到摆动的方向一点点转动：转动的不是摆，是我们脚下的地球。
- 观众起点：看过 79 托马斯·杨、80 菲涅耳、候选 08 费马更好。
- 物理部分（不推导）：
  1. **齿轮法测光速**：光从齿缝穿出去，到远处镜子反射回来。如果齿轮转得够快，光回来时，原来的缝已经转走，换成了一个齿——光被挡住。从齿轮的转速和齿数，算出光往返的时间（**值得记**：c ≈ 3×10⁸ m/s；8.6 km 往返约 57 微秒）。
  2. **光在水里慢**：微粒说（牛顿）认为光进入水会变快，波动说认为变慢。傅科的旋转镜实验显示：变慢——波动说胜（回扣候选 08 费马：光走最省时间的路，需要光在水里慢）。
  3. **傅科摆**：摆一旦摆起来，摆动的平面在空间里保持不变（没有力让它转）。可地球在它下面转，所以从地面上看，摆的方向在慢慢旋转。在北极，一天转一整圈；在巴黎（北纬约 49°），大约 32 小时转一圈（**值得记**：T = 24 h / sin φ，了解结论即可）；在赤道，不转。
  4. 陀螺仪（一句话）：傅科还用一个高速旋转的陀螺演示地球自转，并给它起了名字“gyroscope”。
- 钩子：巴黎先贤祠，穹顶下垂下一根长长的钢丝，下面挂着一个大铁球，地上撒着一圈细沙。球摆了几个小时，沙上的划痕慢慢转了一个角度。“没有人推它。转的，是我们。”
- 章节：两人都生于 1819 年巴黎 → 菲佐：富裕的医生家庭，学医后转向物理（开拍核）→ 傅科：学医，怕见血，转向物理（据说 → 开拍核）→ 银版照相：1845 年两人合作拍下太阳的照片 → 分道扬镳，竞争测光速 → 1848 年菲佐：光的多普勒效应（回扣 85 多普勒）→ 1849 年菲佐：齿轮法，叙雷讷到蒙马特尔约 8.6 公里 → 1850 年傅科：旋转镜，光在水里更慢 → 1851 年菲佐：流水中的光速实验（后来成为相对论的证据之一 → 一句话）→ 1851 年傅科摆：先在自家地下室，再到巴黎天文台，最后在先贤祠公开展示 → 1852 年陀螺仪 → 1862 年傅科更精确的光速值 → 1868 年傅科去世（48 岁），菲佐 1896 年去世 → 回顾。
- 不讲：科里奥利力的数学（一句话：“地球自转带来的看不见的力”）。
- 结尾：“我们每天都站在一个转动的球上，却从来感觉不到。一根钢丝、一个铁球，就让所有人亲眼看见了。”
- 配乐：古典（先贤祠钩子）→ Entropy（齿轮与镜子）→ 紧张（竞争）→ Awakening（摆转了 = 高潮）→ 尾。
- 封面：先贤祠穹顶下的巨大摆锤，地上一圈沙中的划痕；钩子“一只摆证明地球在转”。

## 字幕稿

**开场**
- 巴黎，先贤祠。
- 穹顶下垂下一根六十多米长的钢丝，
- 下面挂着一个大铁球。
- 它来回摆动了几个小时，
- 摆动的方向，慢慢转了一个角度。
- 没有人推它。
- 转的，是我们脚下的地球。

**章节 · 两个巴黎人**

**第一幕 · 同一年**
- 1819 年，巴黎出生了两个男孩：
- 菲佐，和傅科。
- 两人都学过医，后来都转向了物理。

**第二幕 · 太阳的照片**
- 1840 年代，照相术刚刚发明。
- 两人一起研究，
- 拍下了最早的太阳照片之一。
- 可没过多久，他们分道扬镳，
- 成了竞争对手。

**章节 · 光速**

**第三幕 · 八公里**
- 他们比赛的，是同一件事：
- 在地面上，测出光有多快。
- 1849 年，菲佐先做到了。
- 他在巴黎郊外一座房子里放了一个光源，
- 在大约八公里外的蒙马特尔高地上放了一面镜子。

**第四幕 · 齿轮**
- 光从一个齿轮的缝里穿出去，
- 到镜子上反射回来。
- 齿轮慢慢转，光能从同一个缝里回来；
- 转得够快，光回来的时候，缝已经转走了，
- 换成了一个齿，光就被挡住了。
- 从齿轮的转速，就能算出光往返用了多少时间。
- 菲佐得到的光速，大约是每秒三十一万公里。

**第五幕 · 镜子**
- 傅科换了一种办法：用一面高速旋转的镜子。
- 1850 年，他用这个方法证明：
- 光在水里，比在空气里更慢。
- 按照牛顿的微粒说，光在水里应该更快；
- 按照波动说，光在水里应该更慢。
- 实验站在了波动说一边。

**章节 · 摆**

**第六幕 · 地下室**
- 1851 年初，傅科在自家的地下室里，
- 挂起了一只摆。
- 他发现，摆动的方向，在慢慢地转。

**第七幕 · 为什么会转**
- 一只摆一旦摆起来，
- 它摆动的方向，在空间里是不变的，
- 没有什么力让它转。
- 可是，地球在它下面转。
- 所以，站在地上看，摆的方向就在慢慢旋转。
- 在北极，一天转一整圈；
- 在巴黎，大约三十二个小时转一圈；
- 在赤道上，它不转。

**第八幕 · 先贤祠**
- 同年，傅科在先贤祠的穹顶下，
- 挂起了一根六十七米长的钢丝，
- 和一个二十多公斤的铁球。
- 巴黎人排着队来看，
- 亲眼看着摆的方向一点点转动。
- 人类第一次，不用看天上的星星，
- 就看见了地球在转。

**章节 · 之后**

**第九幕 · 陀螺**
- 第二年，傅科又用一个高速旋转的陀螺，演示了地球的自转，
- 还给它起了名字：gyroscope，陀螺仪。
- 1868 年，傅科去世，只有四十八岁。
- 菲佐一直活到 1896 年。

**结尾**
- 我们每天都站在一个转动的球上，
- 却从来感觉不到。
- 一根钢丝、一个铁球，
- 让所有人亲眼看见了。

**回顾**：先贤祠的摆 → 同一年 → 太阳的照片 → 分道扬镳 → 八公里 → 齿轮 → 每秒三十一万公里 → 旋转镜 → 光在水里更慢 → 地下室 → 为什么会转 → 三十二个小时 → 先贤祠 → 陀螺仪

## 值得记住（给用户）
- 光速 c ≈ 3.0×10⁸ m/s。**必记。**
- 傅科摆进动周期 T = 24 h / sin φ（φ 为纬度）。**了解结论即可，不必推导。**
- 介质中光速 v = c/n < c。
