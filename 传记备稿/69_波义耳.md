## 开拍简报（草案）
- 一句话主题：爱尔兰最富有的伯爵的第十四个孩子波义耳，在伊顿读书，十几岁游学意大利时正赶上伽利略的晚年；回国后，他把钱和时间都花在了实验上：和助手胡克一起改进了抽气机，把空气从玻璃罐里抽走，看蜡烛熄灭、铃声消失；他用一根 J 形玻璃管证明：温度不变时，空气被压得越小，压强就越大，两者的乘积不变——波义耳定律。他写了《怀疑的化学家》，主张化学要靠实验，而不是古老的“四元素”；他是英国皇家学会的创始人之一，却因为不愿宣誓，拒绝当会长。
- 观众起点：看过 68 帕斯卡与托里拆利、71 胡克（A 档，他的助手）。
- 物理部分（课本公式）：
  1. **波义耳定律** pV = 常数（温度不变）（**值得记**）：把空气压到原来的一半，压强变成两倍。
  2. **J 形管实验**：J 形玻璃管短的一端封闭，从长的一端灌水银，水银越多，封在短端的空气被压得越短；记下水银高度差和空气长度，乘积几乎不变。
  3. **抽气机实验**：抽走空气后，铃铛的声音越来越小——声音需要介质；蜡烛熄灭、小动物窒息——燃烧和呼吸都需要空气里的某种成分（字幕避免详细描述动物实验，只一句）。
  4. 和后来的查理定律、盖-吕萨克定律合起来 → pV = nRT（**值得记**，一句话预告）。
- 钩子：一个透明的玻璃罐，里面挂着一只正在响的铃铛。随着空气被一点点抽出去，铃声越来越小，最后，铃锤还在敲，却什么也听不见了。
- 章节：爱尔兰利斯莫尔城堡（科克伯爵的第十四个孩子）→ 伊顿公学 → 游学欧洲，1641 年冬在佛罗伦萨读伽利略（伽利略 1642 年 1 月去世，开拍核）→ 回国，牛津，“无形学院”→ 雇胡克当助手 → 改进格里克的抽气机（“波义耳机器”）→ 1660 年《关于空气弹性的物理力学新实验》→ 有人反对（耶稣会士林纳斯），他用 J 形管回应 → 1662 年：pV 不变（陶利、鲍尔先提出，他书里还把鲍尔的工作误记到陶利名下）→ 1661 年《怀疑的化学家》：反对四元素，区分混合物和化合物 → 皇家学会创始人之一，1680 年因不愿宣誓拒任会长 → 和姐姐拉内拉夫人在伦敦一起生活、做实验二十多年 → 1691 年 12 月 31 日去世，比姐姐晚一个星期 → 遗嘱设立“波义耳讲座”→ 回顾。
- 不讲：神学著作（一句话）；动物实验的细节。
- 结尾：“他说，化学不该是炼金术士的秘方，而应该是可以重复的实验。”最后一句：“从一根 J 形的玻璃管开始，空气，第一次有了一条可以计算的规律。”
- 配乐：安静 + 铃声（钩子）→ Entropy（贵族少年、游学）→ Awakening（J 形管 pV 不变 = 高潮）→ 尾。
- 封面：一个玻璃钟罩，里面一只铃铛；旁边一根 J 形管；钩子“压一半，压强加倍”。
- 片尾剪影（按内容顺序）：1656 年荷兰海牙，一个年轻人给钟装上了一个摆，钟一下子准了几十倍 → “下一期：摆钟与光的波。”

## 字幕稿

**开场**
- 一个透明的玻璃罐，里面挂着一只铃铛，正在响。
- 有人开始把罐子里的空气一点点抽出去。
- 铃声越来越小，越来越小。
- 最后，铃锤还在敲，
- 却什么也听不见了。
- 做这个实验的人，叫波义耳。

**章节 · 伯爵的儿子**

**第一幕 · 利斯莫尔城堡**
- 1627 年，波义耳出生在爱尔兰的一座城堡里，
- 父亲是当时最富有的人之一，科克伯爵。
- 他是家里的第十四个孩子。

**第二幕 · 游学**
- 他在英国的伊顿公学读书，
- 十几岁就跟着家庭教师游历欧洲。
- 1641 年冬天，他在意大利佛罗伦萨，
- 读到了伽利略的著作——
- 那时，伽利略就在佛罗伦萨郊外，生命只剩下最后几个月。

**第三幕 · 实验**
- 回到英国，他不用为生计发愁，
- 把钱和时间都花在了实验上。
- 在牛津，他和一群喜欢做实验的人定期聚会，
- 他们后来成了英国皇家学会的核心成员。

**章节 · 空气**

**第四幕 · 抽气机**
- 他雇了一个心灵手巧的年轻助手：胡克。
- 两个人一起改进了一台抽气机，
- 能把玻璃罐里的空气抽走。
- 他们做了一个又一个实验：
- 铃声在真空里消失了——声音需要空气来传播；
- 蜡烛在真空里熄灭了——燃烧需要空气。

**第五幕 · 空气有弹性**
- 1660 年，他把这些实验写成了一本书。
- 他说：空气像弹簧一样，有弹性，
- 被压缩，就会往外推。
- 有人不同意，说他的解释是胡说。
- 波义耳决定，用一个更精确的实验来回答。

**第六幕 · J 形管**
- 他拿来一根弯成 J 形的玻璃管，
- 把短的一端封死，
- 从长的一端灌进水银。
- 水银把一小段空气关在了短的那一端。
- 他一点一点往里加水银，
- 被关住的空气，被压得越来越短。

**第七幕 · 乘积不变**
- 他记下了每一次空气的长度，和水银的高度差。
- 结果发现：
- 空气被压到一半，压强就变成两倍；
- 压到三分之一，压强就变成三倍。
- 压强乘以体积，几乎不变。
- 这就是波义耳定律。
- 其实，另外两位英国人比他更早想到了这一点，
- 他在书里也提到了别人的工作。

**章节 · 化学**

**第八幕 · 怀疑的化学家**
- 1661 年，他写了另一本书：《怀疑的化学家》。
- 两千年来，人们相信，世界由土、水、气、火四种元素组成。
- 波义耳说：不要相信古人怎么说，
- 要看实验怎么说。
- 他还区分了“混合物”和“化合物”。
- 后来，人们称他为近代化学的开创者之一。

**第九幕 · 不愿宣誓**
- 他是英国皇家学会的创始人之一。
- 1680 年，学会推选他当会长，
- 可当会长需要宣誓，
- 他出于宗教上的顾虑，拒绝了。

**第十幕 · 姐姐**
- 他一生没有结婚。
- 后半生，他和姐姐拉内拉夫人一起住在伦敦，
- 在家里建了实验室，一起生活、做研究二十多年。
- 1691 年 12 月，姐姐去世。
- 一个星期后，12 月 31 日，波义耳也去世了。

**结尾**
- 他说，化学不该是炼金术士的秘方，
- 而应该是谁都可以重复的实验。
- 从一根 J 形的玻璃管开始，
- 空气，第一次有了一条可以计算的规律。

**回顾**：真空里的铃铛 → 伯爵的第十四个孩子 → 佛罗伦萨 → 牛津 → 胡克 → 抽气机 → 声音需要空气 → 空气有弹性 → J 形管 → 压一半，压强加倍 → pV 不变 → 怀疑的化学家 → 不愿宣誓 → 姐姐

## 值得记住（给用户）
- 波义耳定律：等温时 p₁V₁ = p₂V₂。**必考。**
- 理想气体状态方程 pV = nRT，R ≈ 8.31 J/(mol·K)。**直接记。**

## 查证结果（2026-10-23 网页核对）
**已核实**
- 1627 年生于爱尔兰沃特福德郡利斯莫尔城堡，第一代科克伯爵的第十四个孩子。
- 伊顿公学；1641 年在意大利学习年迈伽利略的著作。
- 在胡克帮助下改进格里克的真空泵；1660 年《关于空气弹性的物理力学新实验》。
- 波义耳定律：温度不变时气体体积与压强成反比；鲍尔 1661 年已提出，波义耳 1662 年的书误把鲍尔的论文归于陶利。
- 《怀疑的化学家》（1661）：化学研究物质的组成；区分混合物与化合物；常被视为第一位近代化学家。
- 皇家学会创始人之一，1663 年会员；1680 年因对宣誓的顾虑拒任会长。
- 遗嘱设立波义耳讲座。
- 1691 年 12 月 31 日在伦敦去世，比与他同住二十多年的姐姐拉内拉夫人晚一周。
