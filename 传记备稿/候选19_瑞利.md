## 开拍简报（草案）
- 一句话主题：英国贵族出身的瑞利（原名约翰·威廉·斯特拉特），小时候体弱多病，却在剑桥以数学考试第一名毕业。1871 年，他算出了天空为什么是蓝的：空气分子散射蓝光的本领，比红光强好几倍。他继承男爵爵位后，在自家庄园里建了实验室；麦克斯韦去世后，他接任卡文迪许实验室主任。1890 年代，他发现：从空气里提取的氮气，比从化学反应里制得的氮气重了大约千分之五——他没有放过这个微小的差别，和化学家拉姆齐一起追下去，发现了一种全新的元素：氩。1904 年他获得诺贝尔物理学奖，拉姆齐同年获得化学奖。他还写了《声学理论》，提出了光学仪器的“分辨率极限”。
- 观众起点：无需前置；看过 2 麦克斯韦（光是电磁波）更好。
- 物理部分（不推导）：
  1. **散射**：阳光里有各种颜色。光照到比它的波长小得多的空气分子上，分子会被“晃动”起来，向四面八方重新发出光——这叫散射。
  2. **蓝光散射得多**：散射的强弱和波长的四次方成反比（**值得记**：I ∝ 1/λ⁴）。蓝光波长约 450 纳米，红光约 700 纳米，(700/450)⁴ ≈ 6——蓝光被散射得比红光多大约六倍。所以天空四面八方都是被散射过来的蓝光。
  3. **为什么不是紫色**：紫光散射得更多，但阳光里紫光本来就少，人眼对紫光也不敏感（开拍核措辞）。
  4. **夕阳为什么红**：傍晚阳光要斜穿很厚的大气层，蓝光一路被散射掉了，剩下到达眼睛的主要是红光和橙光。
  5. **小数点后第三位**：空气中的“氮”密度 1.2572 g/L，化学法制得的氮 1.2505 g/L（开拍核数据），差约 0.5%——这个差别来自混在空气“氮”里的氩。
- 钩子：白天抬头，天是蓝的；傍晚看夕阳，太阳是红的。“这两件事，其实是同一个原因。”
- 章节：埃塞克斯出生（1842）→ 早产、体弱，多次因病中断学业 → 剑桥三一学院，1865 年数学荣誉考试第一名（Senior Wrangler）→ 1871 年：天空为什么是蓝的 → 同年结婚（妻子是贝尔福的妹妹 → 开拍核，可不写）→ 1873 年继承爵位，成为瑞利男爵 → 在自家特灵庄园建实验室 → 1877 年《声学理论》→ 1879 年麦克斯韦去世，接任卡文迪许教授（1879–1884）→ 回到庄园，精确测量气体密度 → 1892 年：氮气重了千分之五 → 写信给《自然》征求解释 → 与拉姆齐合作 → 1894 年宣布发现氩 → 1904 年诺贝尔物理学奖（拉姆齐获化学奖）→ 瑞利-金斯公式与“紫外灾难”（回扣 11 普朗克，一句话）→ 剑桥大学校长 → 1919 年 6 月去世 → 回顾。
- 不讲：散射公式的推导；瑞利-金斯公式的细节。
- 结尾：“一个是抬头就能看见的蓝天，一个是小数点后第三位的差别。他两样都没有放过。”

## 字幕稿

**开场**
- 白天抬头，天空是蓝的。
- 傍晚看夕阳，太阳是红的。
- 这两件事，其实是同一个原因。
- 第一个把它算清楚的人，叫瑞利。

**章节 · 男爵**

**第一幕 · 体弱的孩子**
- 1842 年，约翰·威廉·斯特拉特出生在英国埃塞克斯的一个贵族家庭。
- 他是早产儿，从小体弱多病，
- 上学多次因病中断。

**第二幕 · 第一名**
- 可他进了剑桥大学，
- 1865 年，在数学荣誉考试里考了第一名。

**章节 · 蓝天**

**第三幕 · 散射**
- 阳光里，混着各种颜色的光。
- 空气分子比光的波长小得多。
- 光照到它们身上，会让它们“晃动”起来，
- 再向四面八方，重新发出光。
- 这叫散射。

**第四幕 · 四次方**
- 1871 年，瑞利算出：
- 散射的强弱，和波长的四次方成反比。
- 蓝光的波长短，红光的波长长。
- 一算：蓝光被散射得，比红光多大约六倍。
- 所以，无论你往天空的哪个方向看，
- 看到的，都是被空气散射过来的蓝光。

**第五幕 · 夕阳**
- 傍晚，阳光要斜着穿过厚厚的大气层，
- 一路上，蓝光都被散射掉了，
- 最后到达你眼睛的，主要是红光和橙光。
- 天是蓝的，夕阳是红的——同一个原因。

**章节 · 庄园**

**第六幕 · 继承爵位**
- 1873 年，他继承了父亲的爵位，成为第三代瑞利男爵。
- 他没有去过贵族的悠闲日子，
- 而是在自家的庄园里，建了一座实验室。

**第七幕 · 卡文迪许**
- 1879 年，麦克斯韦去世。
- 瑞利接任剑桥卡文迪许实验室的主任。
- 五年后，他回到庄园，继续自己的研究。

**章节 · 千分之五**

**第八幕 · 两种氮**
- 他想精确地测量各种气体的密度。
- 他发现了一件怪事：
- 从空气里去掉氧气等成分后得到的“氮气”，
- 比用化学反应制出来的氮气，
- 重了大约千分之五。

**第九幕 · 不放过**
- 千分之五，是小数点后第三位的差别。
- 很多人会把它当作测量误差。
- 瑞利没有。
- 他给《自然》杂志写信，请大家帮忙想想原因。

**第十幕 · 氩**
- 化学家拉姆齐和他一起，把这个差别追了下去。
- 1894 年，他们宣布：
- 空气里的“氮”，混着一种从来没人发现过的气体。
- 它几乎不和任何东西发生反应，
- 他们给它起名叫“氩”，希腊文的意思是：懒惰。

**第十一幕 · 1904**
- 1904 年，瑞利获得了诺贝尔物理学奖，
- 拉姆齐同一年获得了诺贝尔化学奖。
- 1919 年，瑞利去世，七十六岁。

**结尾**
- 一个是抬头就能看见的蓝天，
- 一个是小数点后第三位的差别。
- 他两样都没有放过。

**回顾**：蓝天和夕阳 → 体弱的孩子 → 剑桥第一名 → 散射 → 四次方 → 六倍 → 夕阳 → 继承爵位 → 庄园实验室 → 卡文迪许 → 两种氮 → 千分之五 → 不放过 → 氩 → 1904
