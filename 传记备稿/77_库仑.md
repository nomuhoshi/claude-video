## 开拍简报（草案）
- 一句话主题：库仑是法国军队的工程师，在加勒比海的马提尼克岛修了好几年要塞，回来时身体也垮了；他研究过土墙会被压垮的力、摩擦力的规律，也研究细金属丝被扭转时的回复力——这让他造出了极其灵敏的扭秤。1785 年，他用扭秤测量两个带电小球之间的力，发现：力和距离的平方成反比，就像牛顿的引力一样。这就是库仑定律。电荷的单位“库仑”以他命名。
- 观众起点：看过 74 富兰克林（正负电）、75 卡文迪许（扭秤称地球）、牛顿（平方反比）。
- 物理部分（课本公式）：
  1. **扭秤原理**：细丝被扭转的角度，和扭它的力矩成正比。丝越细越长，就越灵敏——一点点力，就能让它转过明显的角度。
  2. **库仑定律** F = kq₁q₂/r²，k ≈ 9.0×10⁹ N·m²/C²（**值得记**）。
  3. **他怎么改变电荷量**（漂亮的实验技巧）：没有“电荷表”，他就让带电的小球碰一下一模一样的不带电小球，电荷就平分成两半——这样就能得到 1/2、1/4、1/8 的电荷。
  4. **和引力比**：两个质子之间，电力比引力大约强 10³⁶ 倍（回扣频道已有视频）。
  5. 他还发现：磁极之间的力，也遵守平方反比。
- 钩子：一根比头发还细的金属丝，吊着一根轻轻的横杆，横杆一头是一个小小的木髓球。把另一个带电的小球靠近，横杆慢慢转了一个角度。“就是这么一个小装置，让电学第一次有了一条可以计算的定律。”
- 章节：昂古莱姆（1736）→ 巴黎求学，学数学和工程 → 1761 年加入军队工兵 → 1764–1772 年在马提尼克修建波旁堡（热带的疾病，健康受损）→ 1776 年土压力的楔体理论（今天挡土墙设计的基础，一句话）→ 1779 年摩擦力的规律（与阿蒙顿的定律）→ 1784 年金属丝扭转的研究 → 扭秤 → 1785 年电学与磁学论文：平方反比 → “碰一下，电荷平分”的技巧 → 大革命时退居布卢瓦 → 被召回巴黎参与统一度量衡 → 1806 年在巴黎去世 → 1880 年电荷单位“库仑”→ 埃菲尔铁塔上的 72 个名字之一 → 回顾。
- 不讲：库仑定律的现代精确检验（一句话：今天已经验证到极高的精度 → 开拍核）。
- 结尾：“你家里的每一根电线、每一块电池，里面的电荷都遵守着他量出来的这条规律。”最后一句：“一根细丝，量出了看不见的力。”

## 字幕稿

**开场**
- 一根比头发还细的金属丝，
- 吊着一根轻轻的横杆，
- 横杆的一头，是一个小小的球。
- 把另一个带电的小球靠近它，
- 横杆慢慢地，转过了一个角度。
- 就是这样一个小装置，
- 让电学第一次有了一条可以计算的定律。
- 做出它的人，叫库仑。

**章节 · 工程师**

**第一幕 · 昂古莱姆**
- 1736 年，库仑出生在法国西南部的昂古莱姆。
- 他在巴黎学了数学和工程，
- 1761 年，加入了法国军队的工兵部队。

**第二幕 · 马提尼克**
- 几年后，他被派到加勒比海上的法属马提尼克岛，
- 负责修建一座巨大的要塞。
- 他在那里待了好几年。
- 热带的炎热和疾病，让他的身体变得很差。

**第三幕 · 墙和摩擦**
- 回到法国，他研究的都是工程里的实际问题：
- 一堵挡土墙，要多厚，才不会被后面的土压垮？
- 物体在地上滑动，摩擦力有多大？
- 他总结出了摩擦力的规律，
- 今天的教科书里还在用。

**章节 · 扭秤**

**第四幕 · 扭一扭**
- 他还研究了一件看起来很小的事：
- 一根细金属丝，被扭转时，会产生多大的回复力？
- 他发现：扭转的角度，和扭它的力矩成正比。
- 丝越细、越长，就越容易被扭动，
- 一点点的力，就能让它转过明显的角度。

**第五幕 · 扭秤**
- 他用这个原理，造了一台极其灵敏的仪器：扭秤。
- 用一根细丝吊起一根横杆，
- 外面罩上玻璃罩，挡住空气的扰动，
- 旁边刻上角度。
- 任何一个微小的力，都能被它测出来。

**章节 · 平方反比**

**第六幕 · 1785**
- 1785 年，他用扭秤测量两个带电小球之间的力。
- 他把两个小球的距离，从大变小，
- 记下横杆每次转过的角度。
- 距离变成一半，力变成四倍；
- 距离变成三分之一，力变成九倍。
- 电荷之间的力，和距离的平方成反比——
- 和牛顿的万有引力，一模一样。

**第七幕 · 碰一下，平分**
- 那电荷的大小呢？
- 当时可没有测量电荷的仪表。
- 库仑想了一个巧妙的办法：
- 让带电的小球，碰一下另一个一模一样、不带电的小球，
- 电荷就会平分，各剩一半。
- 再碰一次，剩四分之一。
- 他发现：电荷减半，力也减半。
- 力，和两个电荷的乘积成正比。

**第八幕 · 库仑定律**
- 合在一起，就是今天课本上的库仑定律：
- 两个电荷之间的力，
- 和电荷的乘积成正比，和距离的平方成反比。
- 他还发现，磁极之间的力，也是一样的规律。

**第九幕 · 比引力强多少**
- 同样是平方反比，
- 两个质子之间的电力，
- 比它们之间的引力，大约强十的三十六次方倍。
- 我们身边几乎一切的力——
- 推、拉、摩擦、弹力——本质上都是电力。

**章节 · 之后**

**第十幕 · 革命**
- 法国大革命爆发后，库仑离开军队，退居乡下。
- 后来，他被召回巴黎，
- 参加统一全国度量衡的工作。
- 1806 年，库仑在巴黎去世，七十岁。

**结尾**
- 1880 年，电荷的单位，被命名为“库仑”。
- 他的名字，也被刻在了埃菲尔铁塔上。
- 你家里的每一根电线、每一块电池，
- 里面的电荷，都遵守着他量出来的这条规律。
- 一根细丝，量出了看不见的力。

**回顾**：一根细丝 → 昂古莱姆 → 工兵 → 马提尼克 → 挡土墙和摩擦力 → 扭一扭 → 扭秤 → 1785 → 距离一半力四倍 → 碰一下平分 → 库仑定律 → 比引力强 10³⁶ 倍 → 度量衡 → 埃菲尔铁塔

**片尾剪影（按内容顺序）**

## 值得记住（给用户）
- 库仑定律 F = kq₁q₂/r²，k = 1/(4πε₀) ≈ 9.0×10⁹ N·m²/C²。**必考。**
- 元电荷 e ≈ 1.6×10⁻¹⁹ C。**必记。**
- 两个质子：F电/F引 ≈ 1.2×10³⁶。
