# 78 伏打（Alessandro Volta，1745–1827）

## 开拍简报（草案）
- 一句话主题：意大利博洛尼亚的解剖学家伽伐尼发现，死青蛙的腿在接触金属时会抽动，他认为这是青蛙身体里的“动物电”。科莫来的物理学家伏打一开始相信，后来却怀疑：会不会电不在青蛙身上，而在那两种不同的金属上，青蛙腿只是一个灵敏的“电表”？为了证明这一点，他在 1799 年把锌片、铜片和浸了盐水的纸板一层层叠起来，第一次得到了持续不断的电流——伏打电堆，人类的第一块电池。他把结果写信告诉英国皇家学会，1800 年发表。电压的单位“伏特”以他命名。
- 观众起点：看过 74 富兰克林（静电、莱顿瓶）、77 库仑。
- 物理部分（不推导）：
  1. **静电 vs 电流**：莱顿瓶放电，一闪就没了；伏打电堆能持续供电——电流从此可以拿来做实验（为后来的电解、奥斯特、安培、法拉第铺路，回扣第 1 期法拉第）。
  2. **两种金属 + 盐水 = 电池**：不同金属“抓电子”的本领不同，用导电的盐水把它们连起来，就会有电子从一种金属流向另一种。
  3. **串联加电压**：一节电池电压不大，一层层叠起来（串联），电压就相加。（**值得记**：串联电池组电动势 E总 = nE；内阻也相加 r总 = nr。）
  4. **谁对了**：伏打对了一半——青蛙腿抽动的电来自金属；伽伐尼也对了一半——神经和肌肉里确实有生物电（今天的心电图）。
  5. 家里能做（安全）：柠檬插锌片和铜片，几个串起来，能点亮一个小 LED。
- 钩子：1780 年，博洛尼亚。一间解剖实验室里，一只青蛙的腿被放在桌上，旁边有一台起电机。一道电火花闪过，死去的青蛙腿突然猛地一蹬。
- 章节：
  - 伽伐尼（前半段配角）：1780 年起电机火花与青蛙腿 → 十多年研究 → 1791 年发表“动物电”→ 轰动欧洲（一句话：后来启发了小说《弗兰肯斯坦》的作者）。
  - 伏打：1745 年科莫 → 1775 年改进起电盘 → 1776 年在马焦雷湖边的沼泽里发现了甲烷（“沼气”），1778 年分离出来 → 1779 年帕维亚大学实验物理教授，一做近四十年 → 重复伽伐尼的实验，先相信、后怀疑 → 关键：只有当两种不同的金属连在青蛙身上时，抽动最明显 → 他用自己的舌头试：两种金属放在舌头上下，能尝到一股酸味（开拍核）→ 两人的争论（彬彬有礼）→ 1798 年伽伐尼去世 → 1799 年：锌、铜、盐水纸板，叠成一根柱子 → 1800 年写信给皇家学会，分两部分发表 → 一年之内，英国人就用它把水电解成了氢气和氧气（开拍核）→ 应邀到法兰西学院演示 → 1810 年拿破仑封他为伯爵 → 1827 年在科莫附近去世，82 岁 → 单位“伏特”→ 意大利 1 万里拉纸币 → 回顾。
- 不讲：伽伐尼外甥阿尔迪尼的“尸体电击”表演（可能令人不适，不写）。
- 结尾：“今天你手机里的锂电池，和他那根叠起来的柱子，原理是相通的。”最后一句：“一只青蛙腿的抽动，引出了一场争论；一场争论，引出了第一块电池。”
- 配乐：Nightfall（青蛙腿钩子，配一个轻微的“啪”）→ Entropy（伏打的少年和沼气）→ 辩论感（两人争论）→ Awakening（电堆通电 = 高潮）→ 尾。
- 封面：一根由圆片叠起来的电堆，旁边一只青蛙腿的简笔画；钩子“第一块电池”。
- 片尾剪影（按内容顺序）：19 世纪初伦敦，一位医生让一束光穿过两条细缝，墙上出现明暗条纹 → “下一期：最后一个什么都懂的人。”（79 托马斯·杨已备稿）

## 字幕稿

**开场**
- 1780 年，意大利博洛尼亚，一间解剖实验室。
- 桌上放着一只解剖好的青蛙的腿，
- 旁边，一台起电机正在工作。
- 一道小小的电火花闪过，
- 那只早已死去的青蛙腿，突然猛地一蹬。
- 这一蹬，引出了一场二十年的争论，
- 和人类的第一块电池。

**章节 · 动物电**

**第一幕 · 伽伐尼**
- 做这个实验的，是解剖学家伽伐尼。
- 他发现：不只是电火花，
- 当他用金属工具同时碰到青蛙的神经和肌肉时，
- 青蛙腿也会抽动。
- 他研究了十多年，
- 1791 年发表结论：
- 动物的身体里，本来就有电，他叫它“动物电”。
- 这个发现轰动了整个欧洲。

**章节 · 伏打**

**第二幕 · 科莫**
- 1745 年，伏打出生在意大利北部的科莫。
- 年轻时，他就是研究电的好手，
- 改进过一种能反复产生静电的装置，叫起电盘。

**第三幕 · 沼气**
- 1776 年，他在马焦雷湖边划船，
- 用棍子搅动湖边的淤泥，冒出了一串气泡。
- 他收集起来，发现这种气体能燃烧。
- 那就是甲烷，也就是我们说的沼气。（开拍核情节）
- 1779 年起，他在帕维亚大学当实验物理学教授，一当就是将近四十年。

**第四幕 · 怀疑**
- 伏打读了伽伐尼的论文，自己动手重复实验。
- 一开始，他也相信“动物电”。
- 可他注意到一件事：
- 当连接青蛙的是两种不同的金属，比如铜和铁，
- 青蛙腿抽得最厉害；
- 如果只用一种金属，就几乎不抽。
- 他想：电会不会不是来自青蛙，
- 而是来自那两种不同的金属？
- 青蛙腿，只是一个特别灵敏的“电表”。

**第五幕 · 舌头**
- 他还用自己的舌头做实验：
- 一枚银币放在舌头上面，一片锡放在舌头下面，
- 用导线把它们连起来，
- 舌头上，会尝到一股奇怪的酸味。（开拍核）

**第六幕 · 争论**
- 伽伐尼和伏打，一个说电在动物身上，一个说电在金属上。
- 两个人争论了很多年，
- 但始终彬彬有礼。
- 1798 年，伽伐尼去世了。

**章节 · 电堆**

**第七幕 · 一层一层**
- 为了证明自己是对的，伏打决定：
- 不要青蛙了，只用金属。
- 1799 年，他拿来一片锌、一片铜，
- 中间夹一块浸了盐水的纸板，
- 然后，锌、铜、纸板，锌、铜、纸板……
- 一层一层地，叠成了一根柱子。

**第八幕 · 电流**
- 用导线把柱子的上下两头连起来，
- 导线里，有了持续不断的电流。
- 以前的莱顿瓶，放一次电，一闪就没了；
- 这根柱子，可以一直供电。
- 叠得越多，电压就越高。
- 这就是伏打电堆，人类的第一块电池。

**第九幕 · 1800**
- 1800 年，他把这个发明写信告诉了英国皇家学会。
- 消息传开，全欧洲的科学家都开始造电堆。
- 很快，就有人用它把水分解成了氢气和氧气。
- 有了持续的电流，才有了后来的电磁学，
- 才有了法拉第的发现。

**章节 · 之后**

**第十幕 · 伯爵**
- 伏打应邀到巴黎，向法兰西学院演示他的电堆。
- 1810 年，拿破仑封他为伯爵。
- 1827 年，伏打在家乡科莫附近去世，八十二岁。

**第十一幕 · 都对了一半**
- 那么，伽伐尼和伏打，到底谁对？
- 青蛙腿抽动的那个电，确实来自两种不同的金属——伏打对了。
- 可神经和肌肉里，确实有生物电在传递信号——
- 伽伐尼，也对了一半。
- 今天医院里的心电图，测的就是心脏的生物电。

**结尾**
- 电压的单位，叫“伏特”。
- 你手机里的电池，和他那根一层层叠起来的柱子，原理是相通的。
- 一只青蛙腿的抽动，引出了一场争论；
- 一场争论，引出了第一块电池。

**回顾**：青蛙腿一蹬 → 伽伐尼 → 动物电 → 科莫 → 起电盘 → 沼气 → 怀疑 → 两种金属 → 舌头上的酸味 → 争论 → 锌铜盐水 → 一层一层 → 持续的电流 → 1800 → 伯爵 → 都对了一半 → 伏特

## 值得记住（给用户）
- 串联电池组：E总 = nE，r总 = nr；并联（相同电池）：E总 = E，r总 = r/n。**必考。**
- 1 V = 1 J/C。

## 查证结果（2026-10-23 网页核对）
**已核实**
- 伏打：1745 年 2 月 18 日生于科莫；1775 年改进并推广起电盘；1776 年在马焦雷湖安杰拉的沼泽中发现甲烷，1778 年分离；1779 年任帕维亚大学实验物理教授近 40 年；1799–1800 年发明伏打电堆，以分两部分的信寄给皇家学会，1800 年发表（早期用盛盐水的酒杯，后来用浸盐水的纸板夹在锌、铜电极间）；1810 年拿破仑封他为伯爵；1827 年 3 月 5 日在科莫附近的坎纳戈去世，刚过 82 岁生日；意大利 1 万里拉纸币（1990–1997）印有他和电堆的图案。
- 伽伐尼：1780 年发现死青蛙的腿在电火花下抽动；1791 年发表总结十多年研究的论文，提出“动物电”；伏打先接受后怀疑，认为抽动取决于连接神经和肌肉的金属导体；两人分歧但互相尊重；伏打创造了“伽伐尼电”一词；伽伐尼 1798 年去世；玛丽·雪莱写《弗兰肯斯坦》前读过伽伐尼的报告。
