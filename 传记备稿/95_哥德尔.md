## 开拍简报（草案）
- 一句话主题：布尔诺出生的哥德尔，小时候总爱追问“为什么”，家人叫他“为什么先生”；他在维也纳读书，和维也纳学派的哲学家们讨论逻辑。1931 年，25 岁的他发表了两个定理：任何一个足够强大、又不自相矛盾的数学体系里，一定存在一些真的命题，在这个体系里既无法证明，也无法否定；而且，这个体系无法证明自己不自相矛盾。希尔伯特为全部数学打下完美基础的梦想，就此破灭。他后来逃离纳粹统治下的奥地利，横穿西伯利亚到了美国普林斯顿，成了爱因斯坦最亲密的朋友——爱因斯坦说，他每天去研究所，就是为了能和哥德尔一起走路回家（开拍核原话）。他还为爱因斯坦的方程找到了一个允许“回到过去”的奇特宇宙。晚年，他害怕被人下毒，只吃妻子做的饭；妻子住院后，他拒绝进食，1978 年去世。
- 观众起点：看过 93 希尔伯特、49 冯·诺依曼、第 12 期爱因斯坦。
- 数学部分（不推导，直觉）：
  1. **说谎者悖论**：“这句话是假的。”——如果它是真的，那它就是假的；如果它是假的，那它就是真的。
  2. **哥德尔的句子**：他把“真”换成了“可证明”，构造了一句话：“这句话不能被证明。”——如果它能被证明，那体系就证明了一句假话（自相矛盾）；所以，只要体系不自相矛盾，这句话就不能被证明，而它说的恰恰是对的。一句真的、却证明不了的话。
  3. **怎么让数学“说自己”**：哥德尔给每个符号、每个公式、每个证明都编了一个号码（哥德尔编码），于是“关于数学的命题”变成了“关于数字的命题”。
  4. **两个结论**（**值得记**）：① 足够强的一致的形式系统是不完备的；② 这样的系统不能证明自身的一致性。
  5. 不完备 ≠ “数学没用”（一句话澄清常见误解）。
- 钩子：一句话：“这句话不能被证明。”“它是真的，还是假的？1931 年，一个 25 岁的年轻人用这句话，打碎了数学界最伟大的梦想。”
- 章节：布尔诺（1906，“为什么先生”）→ 维也纳大学，物理转数学，维也纳学派 → 1929 年博士论文：完备性定理（一阶逻辑是完备的）→ 1930 年柯尼斯堡会议上宣布不完备定理（回扣 93：同一会议，希尔伯特说“我们必将知道”）→ 1931 年论文 → 冯·诺依曼最早理解了它的意义（开拍核）→ 集合论：选择公理和连续统假设与 ZF 相容 → 1938 年与阿黛尔结婚 → 纳粹吞并奥地利 → 1940 年横穿苏联、太平洋到美国 → 普林斯顿高等研究院 → 和爱因斯坦散步 → 1947 年入籍面试：他说宪法里有漏洞，可能让美国变成独裁（据说，爱因斯坦和摩根斯特恩在场 → 开拍核）→ 1949 年给爱因斯坦 70 岁生日的礼物：旋转的宇宙，可以回到过去 → 晚年：怕被下毒，只吃阿黛尔做的饭 → 1977 年阿黛尔住院 → 1978 年 1 月去世，营养不良 → 回顾。

## 字幕稿

**开场**
- 请看这句话：
- “这句话不能被证明。”
- 它是真的，还是假的？
- 1931 年，一个二十五岁的年轻人，
- 用一句和它很像的话，
- 打碎了数学界最伟大的梦想。
- 他叫哥德尔。

**章节 · 为什么先生**

**第一幕 · 布尔诺**
- 1906 年，哥德尔出生在当时奥匈帝国的布尔诺，
- 今天属于捷克。
- 他小时候什么都要问为什么，
- 家里人叫他“为什么先生”。

**第二幕 · 维也纳**
- 他到维也纳大学读书，本来学物理，后来转学数学。
- 他参加了一群哲学家和科学家的聚会，叫“维也纳学派”，
- 讨论逻辑、语言和科学的基础。
- 1929 年，他的博士论文证明了一个漂亮的结果：
- 在一种基本的逻辑里，所有真的命题，都可以被证明。

**章节 · 一句话**

**第三幕 · 希尔伯特的梦**
- 那时，大数学家希尔伯特有一个梦想：
- 为全部数学打下一个完美的基础，
- 证明数学是完备的——每个真命题都能被证明；
- 也是一致的——永远不会自相矛盾。
- 年轻的哥德尔，本来也想为这个梦想添砖加瓦。

**第四幕 · 说谎者**
- 有一个古老的悖论：
- “这句话是假的。”
- 如果它是真的，那它就是假的；
- 如果它是假的，那它就是真的。
- 哥德尔把其中的“假”，换成了“不能被证明”。

**第五幕 · 给公式编号**
- 可数学怎么能谈论“自己”呢？
- 哥德尔想了一个绝妙的办法：
- 给每一个符号、每一个公式、每一个证明，都编一个号码。
- 这样，“这个公式能不能被证明”，
- 就变成了“这个数字有没有某种性质”，
- 成了一个关于数字的数学问题。

**第六幕 · 不能被证明的真话**
- 于是，他在数学里，造出了一句话：
- “这句话，不能被证明。”
- 如果它能被证明，
- 那数学就证明了一句假话，自相矛盾了。
- 所以，只要数学不自相矛盾，这句话就不能被证明。
- 而这，正是它说的内容。
- 它是一句真话，却永远无法被证明。

**第七幕 · 两个定理**
- 1931 年，他发表了论文。
- 第一个定理：任何足够强大、又不自相矛盾的数学体系，
- 都一定有真的、却无法证明的命题。
- 第二个定理：这样的体系，无法证明它自己不自相矛盾。
- 希尔伯特的梦想，破灭了。

**第八幕 · 同一个会议**
- 就在 1930 年，哥德尔在柯尼斯堡的一次会议上，
- 第一次宣布了这个结果。
- 而在同一个会议上，希尔伯特发表演讲，结尾说：
- 我们必须知道，我们必将知道。

**章节 · 普林斯顿**

**第九幕 · 逃离**
- 1938 年，纳粹德国吞并了奥地利。
- 哥德尔和妻子阿黛尔决定离开。
- 大西洋已经因为战争很危险，
- 1940 年，他们坐火车横穿苏联，
- 再坐船穿过太平洋，到了美国。
- 他进了普林斯顿高等研究院。

**第十幕 · 散步**
- 在普林斯顿，他和爱因斯坦成了最好的朋友。
- 两个人几乎每天一起走路去研究所，再一起走回家，
- 一路用德语聊天。
- 据说，爱因斯坦晚年说过：
- 我每天去办公室，就是为了能和哥德尔一起走路回家。（开拍核）

**第十一幕 · 宪法的漏洞**
- 1947 年，哥德尔要申请成为美国公民。
- 他认真研究了美国宪法，
- 告诉朋友们：他发现了一个逻辑漏洞，
- 可以让美国合法地变成独裁国家。
- 据说，在入籍面试时，他差点当场说出来，
- 陪他去的爱因斯坦和摩根斯特恩赶紧把话题岔开了。（流传的故事）

**第十二幕 · 回到过去的宇宙**
- 1949 年，爱因斯坦七十岁生日，
- 哥德尔送了他一份礼物：
- 爱因斯坦方程的一个新解，
- 描述一个整体在旋转的宇宙。
- 在这个宇宙里，理论上可以回到过去。

**第十三幕 · 晚年**
- 晚年，哥德尔的精神状况越来越差，
- 他总是害怕有人给他下毒，
- 只吃妻子阿黛尔亲手做的饭。
- 1977 年，阿黛尔生病住院。
- 哥德尔拒绝吃任何东西。
- 1978 年 1 月，他因营养不良去世，七十一岁。

**结尾**
- 他证明了理性的边界，
- 却是用最纯粹的理性做到的。
- 我们不一定能知道一切——
- 这件事，我们知道了。

**回顾**：“这句话不能被证明” → 为什么先生 → 维也纳学派 → 完备性定理 → 希尔伯特的梦 → 说谎者悖论 → 给公式编号 → 不能被证明的真话 → 两个定理 → 同一个会议 → 横穿西伯利亚 → 和爱因斯坦散步 → 宪法的漏洞 → 回到过去的宇宙 → 晚年

## 值得记住（给用户）
- 哥德尔第一不完备定理：足够强的一致形式系统中存在不可判定命题。**结论值得记。**
- 第二不完备定理：这样的系统不能证明自身的一致性。
- 与图灵停机问题（96 期）是同一类结论的两种面貌。

## 查证结果（2026-10-23 网页核对）
**已核实**
- 生于布吕恩（今布尔诺），1906 年；1978 年 1 月去世。
- 1929 年博士论文证明一阶逻辑的完备性定理，1930 年获维也纳大学博士。
- 1931 年发表不完备定理：足以表达算术的形式公理系统不能证明所有关于自然数的真命题，也不能证明自身一致；为此发明哥德尔编码。
- 证明选择公理和连续统假设不能从 ZF 集合论中被否证（可构造宇宙）。
- 德奥合并后，1939 年与妻子阿黛尔离开维也纳，1940 年到美国，进普林斯顿高等研究院。
- 与爱因斯坦成为密友，常一起散步；提出哥德尔度规——爱因斯坦方程的旋转宇宙解，允许闭合类时曲线。
- 晚年患精神疾病，害怕被下毒，只吃阿黛尔做的饭；1977 年阿黛尔住院后他拒绝进食，1978 年 1 月因营养不良去世。
- 1930 年参加柯尼斯堡会议（Wikipedia: Kurt Gödel）；希尔伯特 1930 年柯尼斯堡演讲（93 期已核）。
