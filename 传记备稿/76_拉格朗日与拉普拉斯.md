# 76 拉格朗日与拉普拉斯（Joseph-Louis Lagrange，1736–1813；Pierre-Simon Laplace，1749–1827）

## 开拍简报（草案）
- 一句话主题：都灵出生的拉格朗日，家道中落，17 岁才迷上数学，19 岁就写信给欧拉讨论新的数学方法；欧拉离开柏林后，腓特烈大帝请他接任，说“欧洲最伟大的国王，需要欧洲最伟大的数学家”（开拍核：原话出处）；1788 年，他出版了《分析力学》，整本书没有一张图，只靠方程推出全部力学。他还找到了三体问题的特殊解——今天韦伯太空望远镜就停在其中一个“拉格朗日点”上。诺曼底来的拉普拉斯，靠达朗贝尔的推荐来到巴黎，用五卷《天体力学》把牛顿的引力理论推到极致，还设想过一个知道宇宙中所有粒子位置和速度的“智者”——后人叫它“拉普拉斯妖”；他甚至设想过引力大到连光都逃不出去的星。两人都经历了法国大革命和拿破仑时代。
- 观众起点：看过牛顿、73 欧拉、53 史瓦西（光逃不出去的星）。
- 物理部分（不推导）：
  1. **从“力”到“能量”**：牛顿说 F = ma，要画受力分析图；拉格朗日说：只要写出动能 T 和势能 V，令 L = T − V，再套一个通用的公式，运动方程就自己出来了，不需要画图。（**值得记**：拉格朗日量 L = T − V，大学分析力学的起点。）
  2. **拉格朗日点**：在太阳和地球的引力、以及绕转的离心效应共同作用下，有五个点，放在那里的小物体能和地球“同步”绕太阳转。日-地 L2 点在地球背向太阳一侧约 150 万公里，韦伯太空望远镜就在那里（开拍核）。
  3. **拉普拉斯妖**：如果有一个智者，知道某一刻宇宙中每个粒子的位置和速度、以及所有的力，那么过去和未来都在它眼前——经典力学的决定论（后来被量子力学和混沌动摇，回扣 25 海森堡、92 庞加莱）。
  4. **暗星**：拉普拉斯（和更早的米歇尔）设想，一颗足够大、足够密的星，逃逸速度超过光速，光出不来——黑洞的前身想法（回扣 53）。
- 钩子：一本 1788 年出版的力学书。翻开，一页一页往下翻：全是方程，没有一张图。作者在前言里说：读者在这本书里找不到任何图形（开拍核前言原文）。
- 章节：
  - 拉格朗日：都灵（原名朱塞佩·洛多维科·拉格朗吉亚）→ 家里投机失败，财产散尽 → 原本学法律，17 岁迷上数学 → 1754–56 年给欧拉写信：变分法（欧拉-拉格朗日方程）→ 1766 年接替欧拉去柏林，待了二十年 → 1772 年三体问题的特殊解（拉格朗日点）→ 1787 年到巴黎 → 1788《分析力学》→ 大革命中幸存；参与制定米制 → 1794 年拉瓦锡被处决，他说：砍下这颗头只要一瞬间，再长出一颗这样的头，一百年也未必够（后半句开拍核）→ 1813 年去世，葬先贤祠。
  - 拉普拉斯：诺曼底的博蒙昂诺日（家境说法不一）→ 带着介绍信到巴黎见达朗贝尔 → 军校教职 → 太阳系稳定性 → 星云假说 → 五卷《天体力学》（1799–1825）→ 光逃不出去的星 → 1812《概率的分析理论》→ 1814 年“智者”（拉普拉斯妖）→ 拿破仑任命他为内政部长，六个星期就被撤换 → “我不需要那个假设”（有争议，标注）→ 1827 年去世，临终据说说：我们追逐的，不过是幻影。
- 不讲：两人和其他数学家的恩怨；政治立场。
- 结尾：“牛顿给了我们力；他们给了我们一种不用看图、只靠方程就能推出一切的语言。”
- 配乐：Entropy（翻书钩子）→ 宫廷感（柏林、巴黎）→ Awakening（L = T − V = 高潮一）→ 宇宙感（拉格朗日点、韦伯望远镜）→ 神秘（拉普拉斯妖）→ 尾。
- 封面：一本摊开的书，满页公式，空中漂浮着五个发光的拉格朗日点；钩子“没有图的力学”。
- 片尾剪影（按内容顺序）：1785 年巴黎，一位军队工程师用一根极细的丝吊起一根小针，量出了两个带电小球之间的力 → “下一期：扭秤和平方反比。”

## 字幕稿

**开场**
- 1788 年，巴黎出版了一本力学书。
- 翻开它，一页一页往下翻：
- 全是方程，没有一张图。
- 作者在前言里自豪地说：
- 你在这本书里，找不到任何图形。
- 他叫拉格朗日。

**章节 · 拉格朗日**

**第一幕 · 都灵**
- 1736 年，拉格朗日出生在意大利都灵。
- 家里本来很富有，可父亲投机失败，财产散尽。
- 他后来说：如果家里有钱，我大概就不会去做数学了。（开拍核原话）

**第二幕 · 写给欧拉的信**
- 他本来学法律，十七岁才迷上了数学。
- 不到两年，十九岁的他，
- 就写信给当时最伟大的数学家欧拉，
- 讲他发明的一种新方法：
- 怎样找出让某个量最大或最小的那条曲线。
- 欧拉大为欣赏。
- 这就是今天的“变分法”。

**第三幕 · 柏林**
- 1766 年，欧拉离开柏林，回到俄国。
- 普鲁士的腓特烈大帝邀请拉格朗日接替欧拉，
- 称他是“欧洲最伟大的数学家”。
- 他在柏林待了二十年。

**第四幕 · 五个点**
- 1772 年，他研究三个天体互相吸引时怎样运动。
- 这个问题一般没法精确求解，
- 可他找到了几个特殊的解：
- 在太阳和地球附近，有五个特别的点，
- 放在那里的小物体，会和地球步调一致地绕太阳转。
- 今天，它们叫“拉格朗日点”。
- 韦伯太空望远镜，就停在其中一个点上，
- 离地球大约一百五十万公里。

**第五幕 · 没有图的力学**
- 1787 年，他搬到巴黎。
- 第二年，出版了《分析力学》。
- 牛顿的力学，要画受力图，一个力一个力地分析。
- 拉格朗日说：不需要。
- 只要写出物体的动能和势能，
- 用动能减去势能，代进一个通用的公式，
- 运动的规律，就自己出来了。

**第六幕 · 一颗头**
- 法国大革命爆发，拉格朗日留了下来，
- 参与制定了米和千克的十进制标准。
- 1794 年，化学家拉瓦锡被送上断头台。
- 拉格朗日说：
- 砍下这颗头，只要一瞬间；
- 再长出一颗这样的头，一百年也未必够。（后半句开拍核）
- 1813 年，拉格朗日在巴黎去世，葬在先贤祠。

**章节 · 拉普拉斯**

**第七幕 · 诺曼底**
- 1749 年，拉普拉斯出生在法国诺曼底的一个小村子。
- 他带着一封介绍信，到巴黎去找大数学家达朗贝尔。
- 达朗贝尔帮他在军校找到了教职。

**第八幕 · 天体力学**
- 拉普拉斯把一生最多的精力，用在了天上。
- 牛顿留下了一个担心：
- 行星之间互相吸引，时间长了，太阳系会不会散架？
- 拉普拉斯做了大量计算，
- 写成了五卷本的《天体力学》，
- 把牛顿的引力理论，用微积分的语言推到了极致。

**第九幕 · 太阳系是怎么来的**
- 他还提出：太阳系，
- 也许是由一大团旋转的气体云慢慢收缩形成的。
- 这叫“星云假说”。

**第十幕 · 光逃不出去的星**
- 他还想到：
- 如果一颗星足够大、足够密，
- 从它表面逃出去需要的速度，会超过光速，
- 那它发出的光，就出不来，
- 我们根本看不见它。
- 这是一百多年前，人类对黑洞最早的想象之一。

**第十一幕 · 全知的智者**
- 1814 年，他写道：
- 假如有一个智者，在某一刻知道宇宙中每个粒子的位置和速度，
- 也知道所有的力，
- 那么，对它来说，没有什么是不确定的，
- 未来和过去，都会像现在一样，清清楚楚地呈现在它眼前。
- 后人把这个智者，叫作“拉普拉斯妖”。
- 一百多年后，量子力学告诉我们：这样的智者，不可能存在。

**第十二幕 · 六个星期**
- 1799 年，拿破仑任命拉普拉斯为内政部长。
- 六个星期后，就把他撤了。
- 拿破仑后来说，拉普拉斯把“无穷小”的精神带进了行政管理。（开拍核）
- 还有一个流传很广的故事：
- 拿破仑问他，你的书里为什么没提到上帝？
- 他回答：我不需要那个假设。
- 这个故事是真是假，历史学家至今有争议。

**第十三幕 · 幻影**
- 1827 年，拉普拉斯在巴黎去世。
- 据说，他最后说的话是：
- 我们追逐的，不过是幻影。

**结尾**
- 牛顿给了我们“力”。
- 他们给了我们一种不用看图、只靠方程，
- 就能推出天上地下一切运动的语言。

**回顾**：没有一张图的书 → 都灵 → 家道中落 → 写给欧拉的信 → 变分法 → 柏林 → 五个拉格朗日点 → 韦伯望远镜 → 动能减势能 → 米制 → 拉瓦锡的头 → 诺曼底 → 天体力学 → 星云假说 → 光逃不出去的星 → 拉普拉斯妖 → 六个星期 → 幻影

**片尾剪影（按内容顺序）**
- 1785 年巴黎，一位军队工程师用一根极细的丝，量出了两个带电小球之间的力。
- “下一期：扭秤和平方反比。”

## 值得记住（给用户）
- 拉格朗日量 L = T − V；欧拉-拉格朗日方程 d/dt(∂L/∂q̇) − ∂L/∂q = 0。**分析力学起点，值得记。**
- 日-地 L2 点距地球约 1.5×10⁶ km。

## 查证结果（2026-10-23 网页核对）
**已核实**
- 拉格朗日：1736 年 1 月 25 日生于都灵（原名 Giuseppe Lodovico Lagrangia）；家里因投机失去大部分财产；先学法律，约 17 岁对数学产生兴趣；1754–1756 年给欧拉写信讨论变分法；1766 年欧拉离开后，腓特烈二世邀他去柏林，称他“欧洲最伟大的数学家”，在柏林约二十年；1772 年三体问题特殊解（拉格朗日点）；1787 年迁巴黎；1788 年《分析力学》，据说以不含图为豪；大革命中幸存，1799 年任参议员；影响米、千克的十进制选择；拉瓦锡 1794 年被处决后说“砍下这颗头只用了一瞬间”；1813 年 4 月 10 日在巴黎去世，葬先贤祠。
- 拉普拉斯：1749 年 3 月 23 日生于诺曼底博蒙昂诺日；家境说法不一；带介绍信去巴黎找达朗贝尔，获推荐到军校任教；《天体力学》五卷（1799–1825）；研究太阳系稳定性（他的方法本身不足以证明稳定）；发展星云假说；设想引力大到光无法逃出的大质量恒星；1812 年《概率的分析理论》；1814 年《概率的哲学随笔》中的“智者”（“妖”是后人的叫法）；1799 年 11 月被拿破仑任命为内政部长，约六周后被撤换；“不需要那个假设”的故事有争议；1827 年 3 月 5 日在巴黎去世，据泊松转述的遗言：“啊！我们追逐的不过是幻影。”

- 腓特烈“最伟大的国王需要最伟大的数学家”的说法：Wikipedia 只写“欧洲最伟大的数学家”，字幕已按此写。
