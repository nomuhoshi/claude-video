# 65 阿基米德（Archimedes，约前 287–前 212）

> 查证状态：2026-10-23 用网页核对了主要事实（Wikipedia: Archimedes），结果见文末“查证结果”。第四季“在牛顿之前”开篇。古代人物的故事很多是后人记载，字幕严格区分“史料记载”和“传说”。

## 标题候选
- 主：**阿基米德｜给我一个支点｜科学家传记系列**（19 字）
- 备：阿基米德｜尤里卡｜科学家传记系列（16 字）
- 视频内大字：**一个老人从澡盆里跳出来，喊着“我找到了”**（20 字）

## 开拍简报（草案）
- 一句话主题：西西里岛叙拉古的阿基米德，父亲是天文学家；他算出了浮力的规律、杠杆的规律，用多边形把圆周率夹在 3.1408 和 3.1429 之间，还估算过填满宇宙需要多少粒沙子；罗马人围城时，他造的起重机把战船吊离水面；城破时他被一个罗马士兵杀死。他留下的一份手稿，被一个中世纪的僧侣刮掉字迹写上了祈祷文，一千多年后才被重新认出来。
- 观众起点：零。本期是第四季开篇，高中物理课本里的两条：浮力、杠杆。
- 物理部分（不推导，直接用课本形式）：
  1. **浮力**：物体浸在液体里受到的浮力，等于它排开的那部分液体的重量。F浮 = ρ液 g V排（**值得记**，高中必考）。
  2. **王冠问题**（用中国学生熟悉的单位）：金的密度约 19.3 g/cm³，银约 10.5 g/cm³。同样重 1000 g 的王冠，纯金的体积约 52 cm³；如果掺了银，体积就更大，排开的水更多。
  3. **杠杆原理**：F₁L₁ = F₂L₂（**值得记**）。“给我一个支点，我就能撬动地球”——算一算：要多长的杠杆？（一句话：长到不可能，但原理成立。）
  4. **圆周率**：用正 96 边形从里外夹住圆，得到 223/71 < π < 22/7。
- 钩子：澡盆、溢出的水、一个光着身子跑上街的老人。“这个故事你可能听过。可它是阿基米德死后两百年，一个罗马建筑师写下来的。”
- 章节：叙拉古（父亲菲迪亚斯是天文学家；是否去过亚历山大城不确定，但和那里的学者通信）→ 王冠与澡盆（维特鲁威的记载 → 讲清楚是传说，再讲真正的浮力原理：《论浮体》）→ 杠杆（“给我一个支点”出自帕普斯的记载）→ 圆周率（96 边形）→ 数沙子（《数沙者》：8×10⁶³）→ 罗马围城（前 214 年起；起重机“阿基米德之爪”，几位古代史学家都有记载；“镜子烧船”是很晚才出现的说法，笛卡尔就不信）→ 前 212 年城破，被罗马士兵杀死（马塞勒斯曾下令别伤他）→ “别弄乱我的圆”（后人附会）→ 西塞罗找到他的墓：刻着球和圆柱 → 羊皮书：被刮掉写上祈祷文，1906 年海伯格认出，《方法》重见天日 → 回顾。
- 不讲：穷竭法的细节（一句话：两千年后微积分的先声）。
- 结尾：西塞罗在荆棘丛里找到那块刻着球和圆柱的墓碑。最后一句：“他让我们相信：世界上最难的问题，也可以用一张图、一根杠杆、一盆水去想清楚。”
- 配乐：Entropy（澡盆钩子，轻快）→ Awakening（浮力原理的真正推理 = 高潮之一）→ 战鼓/低频（罗马围城）→ 安静（城破）→ 尾（羊皮书）。
- 封面：一个白胡子老人坐在沙地上画圆，身后海面上一艘战船被巨爪吊起；钩子“给我一个支点”。
- 片尾剪影：16 世纪波兰的一座教堂塔楼上，一位教士在夜里看着行星 → “下一期：一本临终才出版的书。”

## 字幕稿

**开场**
- 一个老人在洗澡。
- 他坐进澡盆，水溢了出来。
- 他突然跳起来，光着身子冲上大街，喊着：
- 尤里卡！我找到了！
- 这个故事，你可能听过。
- 可它是在主人公死后两百年，
- 一位罗马建筑师写下来的。
- 故事是真是假，没人知道。
- 可故事里的这个人，是真的。
- 他叫阿基米德。

**章节 · 叙拉古**

**第一幕 · 天文学家的儿子**
- 大约公元前 287 年，阿基米德出生在西西里岛的叙拉古。
- 那是一座希腊城邦。
- 他的父亲，是一位天文学家。
- 他和当时的学术中心，埃及的亚历山大城，
- 一直保持着通信，
- 把自己的发现写信寄给那里的学者。

**章节 · 浮力**

**第二幕 · 王冠**
- 传说，叙拉古的国王做了一顶金王冠，
- 怀疑工匠偷偷掺了银。
- 他请阿基米德查清楚，
- 但不能把王冠弄坏。

**第三幕 · 一样重，不一样大**
- 金比银重得多。
- 一立方厘米的金，大约 19 克；
- 一立方厘米的银，只有 10 克多一点。
- 同样是 1000 克，
- 纯金王冠的体积大约 52 立方厘米，
- 如果掺了银，体积就会更大。
- 可王冠的形状弯弯曲曲，体积怎么量？

**第四幕 · 溢出来的水**
- 把王冠放进装满水的盆里，
- 溢出来多少水，王冠的体积就是多少。
- 传说，他就是在澡盆里想到这一点的。

**第五幕 · 真正的发现**
- 可阿基米德真正写在书里的，比这更深一层。
- 在《论浮体》里，他写下了一条规律：
- 物体浸在液体里，会受到一个向上的力，
- 这个力，等于它排开的那部分液体的重量。
- 这就是浮力定律。
- 两千多年后，它还写在中学的物理课本上。

**章节 · 杠杆**

**第六幕 · 支点**
- 阿基米德还研究了杠杆。
- 他证明：力乘以力臂，两边相等，杠杆就平衡。
- 一个小小的力，只要力臂足够长，
- 就能撬动巨大的重物。
- 后来的一位希腊数学家记载，
- 他说过一句话：
- 给我一个支点，我就能撬动地球。

**章节 · 数学**

**第七幕 · 圆周率**
- 圆的周长，是直径的多少倍？
- 阿基米德在圆里面画一个正六边形，外面也画一个。
- 圆的周长，一定夹在两个六边形的周长之间。
- 然后，边数翻倍：十二、二十四、四十八，
- 一直到九十六边形。
- 他算出：圆周率，在 3.1408 和 3.1429 之间。

**第八幕 · 数沙子**
- 他还写过一本书，叫《数沙者》：
- 如果用沙子填满整个宇宙，需要多少粒？
- 当时的希腊数字，根本写不了这么大的数。
- 他就自己发明了一套表示大数的方法，
- 算出了一个答案：
- 八后面跟着六十三个零。

**章节 · 围城**

**第九幕 · 巨爪**
- 公元前 214 年，罗马大军围攻叙拉古。
- 据古代史学家记载，
- 阿基米德设计了一种巨大的起重机，
- 从城墙上伸出铁爪，
- 抓住罗马战船的船头，吊离水面，再摔下去。
- 罗马人围城围了两年。

**第十幕 · 镜子？**
- 还有一个更有名的故事：
- 他用镜子聚焦阳光，烧毁了罗马战船。
- 可这个说法，几百年后才第一次出现，
- 很多人都怀疑它，包括哲学家笛卡尔。

**第十一幕 · 公元前 212 年**
- 公元前 212 年，叙拉古城破。
- 罗马将军马塞勒斯下过命令：不要伤害阿基米德。
- 可一个罗马士兵还是杀死了他。
- 后来人们说，他死前正在沙地上画图，
- 对士兵说：别弄乱我的圆。
- 这句话，古代的史料里并没有。

**章节 · 留下的东西**

**第十二幕 · 球和圆柱**
- 阿基米德最得意的一个发现是：
- 一个球，放进一个刚好装下它的圆柱里，
- 球的体积，正好是圆柱的三分之二。
- 他希望把这个图形刻在自己的墓碑上。
- 一百多年后，罗马的西塞罗到西西里做官，
- 在荆棘丛里找到了这块刻着球和圆柱的墓碑。

**第十三幕 · 被刮掉的书**
- 中世纪，一位僧侣需要羊皮纸写祈祷书，
- 他拿来一本阿基米德著作的抄本，
- 把上面的字刮掉，写上了祈祷文。
- 1906 年，丹麦学者海伯格在君士坦丁堡，
- 在祈祷文的下面，认出了阿基米德的文字。
- 里面有一本以为早已失传的书：《方法》，
- 讲他是怎样想出那些面积和体积的——
- 他用的方法，像极了两千年后的微积分。

**结尾**
- 他让我们相信：
- 世界上最难的问题，
- 也可以用一张图、一根杠杆、一盆水，
- 去想清楚。

**回顾**：澡盆 → 天文学家的儿子 → 王冠 → 一样重不一样大 → 浮力定律 → 杠杆 → 给我一个支点 → 96 边形 → 数沙子 → 巨爪 → 镜子？ → 城破 → 球和圆柱 → 被刮掉的书

**片尾剪影**
- 16 世纪，波兰的一座教堂塔楼上，一位教士在夜里看着行星。
- “下一期：一本临终才出版的书。”

## 值得记住（给用户）
- 阿基米德原理：F浮 = ρ液 g V排。**高中必考，直接记住。**
- 杠杆平衡：F₁L₁ = F₂L₂。
- 球的体积 = 外切圆柱体积的 2/3；球的表面积 = 外切圆柱侧面积。
- 223/71 < π < 22/7。

## 查证结果（2026-10-23 网页核对）
**已核实**
- 约前 287 年生于叙拉古（据策策斯“活了 75 岁”推算）；父亲菲迪亚斯是天文学家（见《数沙者》）。
- 是否去过亚历山大城不确定，但与那里的学者通信。
- 王冠与“尤里卡”出自维特鲁威，他晚阿基米德约两百年；另有《度量衡之歌》用秤和浸水的不同版本。
- 浮力原理见《论浮体》。
- “给我一个支点”由帕普斯记载。
- “阿基米德之爪”：普鲁塔克、李维、波利比乌斯都有记载（前 214 年围城）。
- 镜子烧船：最早见于盖伦，卢西安最早记载烧船但没提镜子；笛卡尔不信。
- 前 212 年被罗马士兵杀死，马塞勒斯曾下令不伤他。
- “别弄乱我的圆”不见于古代史料（瓦列里乌斯·马克西穆斯记录了类似的话）。
- 西塞罗任财务官时在西西里找到他的墓，墓上有球和圆柱。
- 用 96 边形得到 223/71 < π < 22/7。
- 1906 年海伯格在君士坦丁堡检视羊皮书；《方法》只存于这份羊皮书中。
- 《数沙者》估计 8×10⁶³ 粒沙。

**写“据说”或开拍再核**
- 西塞罗找到墓的年份（前 75 年）：开拍核，字幕写“一百多年后”。
- 金、银密度：19.3、10.5 g/cm³（常识，可保留）。
- “围城两年”：前 214 年到前 212 年，按年份推算。

**不写**
- 未经史料支持的细节（例如他的死亡经过的各种版本，只选一种并标明）。
