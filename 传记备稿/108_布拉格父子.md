## 开拍简报（草案）
- 一句话主题：英国人威廉·亨利·布拉格，剑桥数学优等生，23 岁就被派到澳大利亚阿德莱德当教授，在那里成家，儿子威廉·劳伦斯·布拉格在阿德莱德出生长大。1912 年，德国的劳厄发现 X 射线穿过晶体会产生规则的斑点；刚从剑桥毕业的儿子在河边散步时想到：可以把它看成 X 射线被晶体里一层层原子“反射”——由此写出了布拉格定律 2d sinθ = nλ。在利兹当教授的父亲造出了 X 射线光谱仪，父子俩一起用它测出了氯化钠、金刚石等晶体里原子的排列。1915 年，父子二人共同获得诺贝尔物理学奖——儿子 25 岁，至今仍是最年轻的诺贝尔物理学奖得主；而那时他正在一战前线，他的弟弟刚刚在加里波利阵亡。后来，儿子领导的卡文迪许实验室里，诞生了 DNA 双螺旋结构和第一批蛋白质的结构。
- 观众起点：看过 16 J.J. 汤姆孙、17 卢瑟福、79 托马斯·杨（双缝干涉）。
- 物理部分（不推导，几何直觉）：
  1. **X 射线是什么**：波长比可见光短几千倍的电磁波，大约 0.1 纳米——正好和晶体里原子之间的距离差不多。
  2. **劳厄斑点**（一句话）：X 射线穿过晶体，在照相底片上留下规则的斑点——晶体就像一个三维的“光栅”。
  3. **布拉格定律**（**值得记**）：晶体里的原子排成一层层平行的“面”，间距为 d。X 射线以角度 θ 打进来，一部分被第一层反射，一部分被第二层反射；第二层反射的那一束多走了 2d sinθ 的路。当这段路程差正好是波长的整数倍，两束光同步、互相加强，出现亮斑：**2d sinθ = nλ**。高中物理选修/大学必考。
  4. **反过来用**：知道 X 射线的波长，测出亮斑出现的角度，就能算出原子层之间的距离——这就是“用 X 射线看见原子的排列”。
  5. **氯化钠的结构**：盐的晶体里，钠和氯一个隔一个排列，并没有一个个独立的“NaCl 分子”（让当时一些化学家很不舒服 → 开拍核）。
- 钩子：1915 年的诺贝尔物理学奖，颁给了两个人：一位 53 岁的父亲，和他 25 岁的儿子。“消息传来的时候，儿子正在法国前线；一个月前，他的弟弟死在了加里波利。”（儿子得知消息时所在地开拍核）
- 章节：父亲：坎伯兰出生（1862）→ 剑桥数学（1884 年第三名）→ 1885 年受聘阿德莱德大学，23 岁当教授 → 在阿德莱德结婚，1890 年儿子出生 → 1896 年在阿德莱德做最早的 X 射线演示（之一）→ 1909 年回英国，利兹大学 → 儿子：阿德莱德大学 → 剑桥三一学院，1912 年毕业 → 1912 年：劳厄的发现 → 儿子在河边散步时想到“反射” → 布拉格定律 → 父亲的 X 射线光谱仪 → 父子合作：氯化钠、金刚石的结构 → 1914 年一战爆发，儿子参军，研究用声音定位敌方炮位 → 1915 年 9 月，弟弟罗伯特在加里波利阵亡 → 1915 年 11 月，父子共获诺贝尔奖 → 功劳归谁？（外界常以为主要是父亲的，据说儿子为此耿耿于怀 → “据说”）→ 父亲：伦敦大学学院、皇家研究所、皇家学会会长，1942 年去世 → 儿子：曼彻斯特、国家物理实验室，接替卢瑟福领导卡文迪许实验室 → 支持佩鲁茨、肯德鲁的蛋白质结构研究 → 1953 年在索尔维会议上宣布沃森和克里克的 DNA 结构 → 皇家研究所的圣诞讲座 → 1971 年去世 → 回顾。
- 不讲：晶体学的倒易空间、傅里叶合成（一句话：后来晶体学家用傅里叶的数学从斑点反推原子位置 → 回扣 81 傅里叶）。
- 结尾：“一个是 X 射线的‘尺子’，一个是读懂这把尺子的人。从盐，到金刚石，到蛋白质，到 DNA——我们今天对物质结构的认识，大半是从这对父子开始的。”
- 配乐：安静（诺奖钩子）→ 温暖（阿德莱德）→ Entropy（剑桥河边）→ Awakening（布拉格定律 = 高潮）→ 悲伤（加里波利）→ 尾。
- 封面：一层层排列的原子，两束 X 射线斜着打进来、反射出去；角落里一老一少两个剪影；钩子“父子同奖”。

## 字幕稿

**开场**
- 1915 年的诺贝尔物理学奖，颁给了两个人：
- 一位五十三岁的父亲，
- 和他二十五岁的儿子。
- 这个儿子，至今仍是最年轻的诺贝尔物理学奖得主。
- 消息传来的时候，他正在战争的前线。（开拍核）
- 就在两个多月前，他的弟弟，死在了加里波利。
- 他们是布拉格父子。

**章节 · 阿德莱德**

**第一幕 · 父亲**
- 1862 年，威廉·亨利·布拉格出生在英格兰北部的坎伯兰。
- 他在剑桥学数学，1884 年以第三名的成绩毕业。
- 1885 年，澳大利亚阿德莱德大学聘请他当教授，
- 那年他才二十三岁。

**第二幕 · 儿子**
- 他在阿德莱德结了婚。
- 1890 年，儿子威廉·劳伦斯·布拉格出生了。
- 儿子在阿德莱德长大，在阿德莱德大学读完了本科，
- 然后跟着回英国的父亲，去了剑桥。

**第三幕 · X 射线**
- 1895 年，伦琴发现了 X 射线。
- 第二年，父亲就在阿德莱德做了 X 射线的公开演示。
- 1909 年，父亲回到英国，在利兹大学当教授。

**章节 · 河边**

**第四幕 · 劳厄的斑点**
- 1912 年，德国物理学家劳厄做了一个实验：
- 让 X 射线穿过一块晶体，
- 照相底片上，出现了一圈规则的斑点。
- 这说明：X 射线是波，
- 而晶体，就像一块三维的“光栅”。
- 可这些斑点的位置，该怎么理解？

**第五幕 · 散步**
- 那一年，儿子刚从剑桥毕业，二十二岁。
- 据说，他是在剑桥的河边散步时，想到了答案：
- 把晶体里的原子，看成一层一层平行的“镜面”。
- X 射线打进来，被每一层都反射一点。

**第六幕 · 布拉格定律**
- 第二层反射回来的那一束，
- 比第一层多走了一段路。
- 如果这段多走的路，正好是波长的整数倍，
- 两束 X 射线就步调一致，互相加强，
- 底片上就出现一个亮斑。
- 写成公式，就是：2d sinθ = nλ。
- 这叫布拉格定律。

**第七幕 · 尺子**
- 反过来用：
- 知道 X 射线的波长，测出亮斑出现的角度，
- 就能算出原子层之间的距离。
- 人类第一次，有了一把能量出原子排列的“尺子”。

**章节 · 父子**

**第八幕 · 光谱仪**
- 父亲在利兹，造出了一台 X 射线光谱仪，
- 能精确地测量 X 射线被晶体反射的角度。
- 儿子出理论，父亲出仪器。
- 父子俩一起，测出了一个又一个晶体的结构。

**第九幕 · 盐**
- 最早被解开的，是食盐。
- 他们发现：盐的晶体里，钠和氯一个隔一个地整齐排列，
- 并没有一个个独立的“氯化钠分子”。
- 后来，他们又测出了金刚石的结构：
- 每一个碳原子，都和四个碳原子紧紧连在一起。

**章节 · 1915**

**第十幕 · 战争**
- 1914 年，第一次世界大战爆发。
- 儿子参了军，
- 在法国研究怎样用声音来测定敌人炮位的位置。
- 1915 年 9 月，他的弟弟罗伯特，
- 在加里波利阵亡。

**第十一幕 · 诺贝尔奖**
- 1915 年 11 月，诺贝尔物理学奖公布：
- 父子二人，因为用 X 射线分析晶体结构，共同获奖。
- 儿子，二十五岁。
- 可外界常常以为，这主要是父亲的功劳。
- 据说，儿子为此耿耿于怀了很多年。

**章节 · 之后**

**第十二幕 · 父亲**
- 父亲后来在伦敦大学学院、皇家研究所工作，
- 当选英国皇家学会会长。
- 1942 年 3 月，他在伦敦去世。

**第十三幕 · 儿子**
- 儿子先后在曼彻斯特大学、国家物理实验室工作，
- 后来接替卢瑟福，领导剑桥的卡文迪许实验室。
- 他支持年轻人用 X 射线去解析更复杂的东西：
- 蛋白质。
- 1953 年，在他领导的实验室里，
- 两个年轻人提出了 DNA 的双螺旋结构。
- 1971 年，他在英国去世，八十一岁。

**结尾**
- 一个造出了 X 射线的“尺子”，
- 一个读懂了这把尺子。
- 从盐，到金刚石，到蛋白质，到 DNA，
- 我们今天对物质结构的认识，
- 很大一部分，是从这对父子开始的。

**回顾**：父子同奖 → 二十三岁的教授 → 阿德莱德 → 劳厄的斑点 → 河边散步 → 一层层的镜面 → 2d sinθ = nλ → 原子的尺子 → 光谱仪 → 盐 → 金刚石 → 战争 → 加里波利 → 1915 → 卡文迪许 → DNA

## 值得记住（给用户）
- **布拉格定律：2d sinθ = nλ**（θ 是 X 射线与晶面的夹角，不是与法线的夹角——常考陷阱）。**必记。**
- X 射线波长 ~0.1 nm，与原子间距同量级。

## 查证结果（2026-10-23 网页核对）
**已核实（父亲）**
- 1862 年 7 月 2 日生于坎伯兰的韦斯特沃德；1884 年剑桥三一学院数学第三名（third wrangler）。
- 1885 年受聘阿德莱德大学，1886 年初到任，时年 23 岁；在阿德莱德与格温多琳·托德结婚。
- 1896 年在阿德莱德做 X 射线演示（克鲁克斯管由塞缪尔·巴伯提供）。
- 1909 年任利兹大学教授；发明 X 射线光谱仪。
- 1915 年伦敦大学学院；1923 年皇家研究所；1935 年皇家学会会长；1942 年 3 月 12 日去世。
- 1915 年与儿子共获诺贝尔物理学奖，获奖理由：用 X 射线分析晶体结构。

**已核实（儿子）**
- 1890 年 3 月 31 日生于阿德莱德；1908 年阿德莱德大学毕业；1912 年剑桥三一学院一等荣誉毕业。
- 1912 年提出布拉格定律（页面称是在河边散步时想到的）。
- 一战中在皇家骑炮兵服役，借调皇家工兵研究声测定位；弟弟 1915 年 9 月 2 日在加里波利阵亡。
- 1915 年与父亲共获诺贝尔物理学奖，时年 25 岁，是最年轻的诺贝尔物理学奖得主。
- 1919–1937 年曼彻斯特大学朗沃西物理学教授；1937 年国家物理实验室主任；卢瑟福去世后接任卡文迪许教授、领导卡文迪许实验室。
- 1953 年在索尔维会议上宣布沃森和克里克的 DNA 结构，后提名二人获诺贝尔奖。
- 皇家研究所自然哲学教授；1934、1961 年做圣诞讲座；1971 年 7 月 1 日在伊普斯威奇附近去世，81 岁。
