## 开拍简报（草案）
- 一句话主题：丹尼尔·伯努利出生在一个“数学家族”：父亲约翰、伯父雅各布都是顶尖数学家。父亲不让他学数学，逼他先学经商、再学医，只在私下教他。他到俄国圣彼得堡当教授，和好友欧拉一起研究；回到巴塞尔后写出《流体力学》（1738），给出了流体里速度和压强之间的关系——伯努利原理；他用“无数小分子乱撞”来解释气体的压强，是气体分子运动论的先驱；他还研究了接种天花疫苗是否值得，用数学讨论“钱对人的价值”。据说，父亲在一次巴黎科学院竞赛中和他并列第一，竟气得把他赶出了家门。
- 观众起点：看过 73 欧拉（A 档，伯努利家的学生和他的朋友）。
- 物理部分（不推导，给结论 + 生活例子）：
  1. **伯努利原理**：同一根水管里，水流得快的地方，压强小；流得慢的地方，压强大。公式 p + ½ρv² + ρgh = 常数（**值得记**，大学流体力学第一条，高中选修也有）。它本质上是能量守恒。
  2. **生活例子**：用嘴往两张纸中间吹气，纸不是被吹开，而是往中间合拢；站台上为什么要站在安全线外。（飞机升力：伯努利原理是其中一部分解释，但常见的“上下两股气流同时到达”的说法是错的——字幕要说明，避免以讹传讹。）
  3. **气体压强从哪来**：无数个看不见的小粒子不停地撞击容器壁，撞得越快、越频繁，压强越大——100 多年后才被麦克斯韦、玻尔兹曼发展成完整理论（回扣第 9 期玻尔兹曼）。
- 钩子：用嘴对着两张垂下来的纸中间用力吹气。“你以为它们会被吹开？它们会贴到一起。”
- 章节：格罗宁根出生（父亲在那里当教授）→ 伯努利家族（父亲约翰、伯父雅各布）→ 父亲逼他学商、学医，私下教他数学 → 巴塞尔、海德堡、斯特拉斯堡学医 → 1724 年去圣彼得堡当数学教授，欧拉也来了 → 1733 年回巴塞尔 → 1734 年和父亲在巴黎科学院竞赛中并列第一，父亲把他逐出家门（开拍核）→ 1738 年《流体力学》：速度与压强 → 气体分子撞墙 → 父亲出版《水力学》，据说把日期写早了（有争议，未核实 → 标注）→ 圣彼得堡悖论：钱对人的“效用”→ 1766 年天花接种的统计分析 → 振动的弦、叠加原理 → 和欧拉研究梁的弹性 → 1782 年在巴塞尔去世 → 回顾。
- 不讲：家族的其他成员（一句话：这个家族三代出了八位数学家 → 开拍核）。
- 结尾：“今天，水管、血管、飞机、喷雾器，都绕不开他写下的那条规律。”最后一句：“速度和压强，此消彼长——就像他和父亲之间。”（开拍斟酌，避免过度戏剧化）
- 配乐：轻快（吹纸钩子）→ 紧张（家族矛盾）→ Entropy（圣彼得堡）→ Awakening（流体力学 = 高潮）→ 尾。
- 封面：两张往中间合拢的纸，中间是一束快速的气流；钩子“速度越大，压强越小”。
- 片尾剪影（按内容顺序）：18 世纪的圣彼得堡，一个几乎失明的人在口述 → “下一期：失明之后，写得更多的人。”（73 欧拉已备稿）

## 字幕稿

**开场**
- 拿两张纸，竖着垂下来，靠近一点。
- 用嘴对着两张纸的中间，用力吹气。
- 你以为，它们会被吹开？
- 不，它们会贴到一起。
- 流得快的空气，压强反而小。
- 写下这条规律的人，叫丹尼尔·伯努利。

**章节 · 数学家族**

**第一幕 · 伯努利家**
- 1700 年，丹尼尔·伯努利出生在荷兰的格罗宁根。
- 他的家族，是欧洲最有名的数学家族：
- 父亲约翰、伯父雅各布，都是顶尖的数学家。

**第二幕 · 不许学数学**
- 可父亲不想让他学数学。
- 他先让儿子学经商，后来又让他学医。
- 只答应私下里教他一点数学。
- 丹尼尔先后在巴塞尔、海德堡、斯特拉斯堡学医，
- 拿到了医学学位。

**第三幕 · 圣彼得堡**
- 1724 年，他应邀去俄国圣彼得堡科学院，当数学教授。
- 不久，他父亲的学生、年轻的欧拉也来了。
- 两个年轻人成了好朋友，一起研究。

**第四幕 · 赶出家门**
- 1733 年，他回到瑞士巴塞尔。
- 第二年，他参加了巴黎科学院的有奖竞赛，
- 结果，和自己的父亲并列第一。
- 据说，父亲觉得被儿子“平起平坐”是一种羞辱，
- 竟把他赶出了家门。

**章节 · 流体**

**第五幕 · 流体力学**
- 1738 年，丹尼尔出版了一本书：《流体力学》。
- 他研究的是：水和空气流动时，遵守什么规律。

**第六幕 · 快的地方，压强小**
- 想象一根粗细不均匀的水管。
- 水流到细的地方，必须流得更快，
- 才能让同样多的水通过。
- 丹尼尔发现：
- 水流得快的地方，压强小；
- 流得慢的地方，压强大。
- 这就是伯努利原理。
- 本质上，它是能量守恒：
- 速度的能量多了，压强的能量就少了。

**第七幕 · 身边的伯努利**
- 火车高速驶过站台，
- 车身旁边的空气被带着飞快流动，压强变小，
- 站得太近的人，会被外面的空气推向火车。
- 所以，要站在安全线外。
- 飞机的机翼，也和这条规律有关，
- 不过，常听到的“上下两股气流要同时到达机翼后面”，是一个错误的说法。

**第八幕 · 撞墙的小粒子**
- 在同一本书里，他还提出了一个大胆的想法：
- 气体，是由无数看不见的小粒子组成的，
- 它们不停地乱飞，撞到容器的壁上。
- 气体的压强，就是这些小粒子撞墙的结果。
- 撞得越快、越频繁，压强就越大。
- 一百多年后，麦克斯韦和玻尔兹曼才把这个想法发展成完整的理论。

**章节 · 不只是物理**

**第九幕 · 钱的价值**
- 他还想过一个有趣的问题：
- 一百块钱，对穷人和富人，价值一样吗？
- 他说，钱越多，再多一块钱带来的快乐就越少。
- 这个想法，后来成了经济学的基础之一。

**第十幕 · 天花**
- 1766 年，他用统计数据计算：
- 给人们接种天花，虽然有一点风险，
- 但能让人们平均多活多少年。
- 这是最早用数学来评估公共卫生措施的研究之一。

**第十一幕 · 巴塞尔**
- 回到巴塞尔后，他先后当过医学、哲学和物理学教授。
- 1782 年，丹尼尔·伯努利在巴塞尔去世，八十二岁。

**结尾**
- 今天，水管、血管、飞机、喷雾器，
- 都绕不开他写下的那条规律：
- 速度和压强，此消彼长。

**回顾**：吹纸 → 数学家族 → 不许学数学 → 学医 → 圣彼得堡 → 欧拉 → 并列第一 → 赶出家门 → 流体力学 → 快的地方压强小 → 安全线 → 撞墙的小粒子 → 钱的价值 → 天花接种

**片尾剪影（按内容顺序）**
- 18 世纪的圣彼得堡，一个几乎失明的人在口述，他的儿子在旁边写。
- “下一期：失明之后，写得更多的人。”

## 值得记住（给用户）
- 伯努利方程（理想流体、沿流线）：p + ½ρv² + ρgh = 常数。**值得记。**
- 连续性方程：S₁v₁ = S₂v₂（管子细的地方流速大）。**值得记。**

## 查证结果（2026-10-23 网页核对）
**已核实**
- 1700 年 2 月 8 日生于格罗宁根；父亲约翰·伯努利，伯父雅各布·伯努利。
- 父亲逼他先学经商、再学医，答应私下教他数学；在巴塞尔、海德堡、斯特拉斯堡学习。
- 1724 年去圣彼得堡任数学教授，1733 年离开回巴塞尔，在那里先后任医学、形而上学、自然哲学教授直到去世。
- 1738 年《流体力学》，由活力（vis viva）守恒推出结论，奠定气体分子运动论的基础；伯努利原理以他命名。
- 圣彼得堡悖论：钱的效用与风险厌恶；1766 年分析天花接种数据。
- 振动弦、叠加原理；与欧拉研究弹性和梁。
- 在巴黎科学院竞赛中与父亲并列第一；父亲禁止他进家门。

**写“据说”或开拍再核**
- 去世日期：Wikipedia 写 1782 年 3 月 27 日，常见说法 3 月 17 日，开拍核；字幕只写年份。
- 并列第一的年份（1734）：开拍核。
- 父亲《水力学》倒填日期抄袭：Wikipedia 标注“据称”且缺引用，字幕不写。
- 欧拉 1727 年到圣彼得堡（73 期已核）。
- 站台安全线、吹纸：生活演示，物理正确。
- 飞机升力“同时到达”谬误：物理常识。
- 去世年龄 82 岁：按生卒推算。
