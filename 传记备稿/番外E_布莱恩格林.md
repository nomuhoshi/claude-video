## 开拍简报（草案）
- 一句话主题：纽约出生的布莱恩·格林，从哈佛物理系毕业后，以罗德学者的身份去牛津读博士，研究弦理论里额外维度的形状。他和合作者发现了“镜像对称”：两种形状完全不同的额外维度，可以给出完全相同的物理；他还证明，在弦理论里，空间的结构可以“撕开”再平滑地“缝合”。1999 年，他写了《宇宙的琴弦》（The Elegant Universe），入围普利策奖，后来被拍成美国公共电视台的纪录片，获得皮博迪奖。2008 年，他和前新闻制片人特蕾西·戴一起创办了“世界科学节”。他还在电影《黑洞频率》里客串，在《生活大爆炸》里本色出演。
- 观众起点：无需前置；看过 104 南部阳一郎（弦）更好。
- 物理部分（不推导）：
  1. **琴弦的泛音**：一根两端固定的琴弦，只能以特定的方式振动：一整段、两段、三段……对应基音和一个个泛音（**值得记**：驻波频率 fₙ = n·v/(2L)，高中必考）。
  2. **弦理论的想法**：所有的基本粒子，也许都是同一种极小的弦，只是振动方式不同——就像同一根琴弦，能拨出不同的音。电子是一种“音”，夸克是另一种“音”。
  3. **额外的维度和镜像对称**（比喻，一句话）：弦理论需要额外的卷起来的维度（回扣番外 D）；这些维度可以卷成很复杂的形状，而格林和合作者发现，两种看起来完全不同的形状，竟然给出一模一样的物理——就像两把形状完全不同的乐器，奏出了完全相同的音色。
  4. **空间可以撕开再缝合**（一句话）：在弦理论里，空间的“形状”可以平滑地改变，甚至撕开一个口子再补上，而物理不会出问题（开拍核措辞）。
- 钩子：拨一根吉他弦，慢镜头，弦上出现一个、两个、三个“波腹”。“一根弦，能发出很多种音。如果宇宙里所有的粒子，都是一根弦在振动呢？”
- 章节：纽约出生（1963）→ 哈佛物理 1984 年毕业 → 罗德学者，牛津莫德林学院，1987 年博士 → 镜像对称 → 空间拓扑的平滑改变（翻转、锥形转变）→ 1990 年康奈尔大学，1995 年正教授 → 1996 年哥伦比亚大学正教授，主持理论物理中心 → 1999 年《宇宙的琴弦》，入围普利策 → 2003 年 NOVA 纪录片获皮博迪奖 → 2004 年《宇宙的结构》，2011 年拍成四集纪录片 →《隐藏的现实》《直到时间的尽头》→ 2008 年和特蕾西·戴创办世界科学节 → 客串电影、电视 → 回顾。
- 不讲：卡拉比-丘流形的数学；私生活。
- 结尾：“弦理论到今天还没有被实验证实。但他让很多人第一次觉得，宇宙的深处，也许像一首乐曲。”
- 配乐：吉他泛音（钩子）→ Entropy（哈佛、牛津）→ 神秘（额外维度）→ Awakening（弦的音乐 = 高潮）→ 尾。

## 字幕稿

**开场**
- 拨一根吉他弦。
- 放慢看，弦上出现了一个、两个、三个“鼓包”。
- 一根弦，能发出很多种音。
- 如果宇宙里所有的粒子，
- 都是一根极小的弦，在用不同的方式振动呢？
- 把这个想法讲给全世界听的人之一，叫布莱恩·格林。

**章节 · 弦**

**第一幕 · 纽约**
- 1963 年，布莱恩·格林出生在纽约。
- 他在哈佛大学学物理，1984 年毕业，
- 然后作为罗德学者，去英国牛津大学读博士，
- 1987 年拿到学位。

**第二幕 · 琴弦**
- 一根两端固定的琴弦，只能以几种特定的方式振动：
- 整根一起振，是最低的音；
- 分成两段振，音高一倍；
- 分成三段，再高……
- 这就是基音和泛音。

**第三幕 · 粒子是音符**
- 弦理论说：所有的基本粒子，
- 也许都是同一种极小的弦，只是振动的方式不同。
- 电子，是一种“音”；
- 夸克，是另一种“音”。

**章节 · 形状**

**第四幕 · 卷起来的维度**
- 可弦理论有一个奇怪的要求：
- 空间，要比我们熟悉的三维更多。
- 多出来的维度，卷得极小，卷成复杂的形状。
- 形状不同，弦的振动方式就不同，
- 我们看到的粒子也就不同。

**第五幕 · 镜像对称**
- 格林和合作者发现了一件奇怪的事：
- 两种看起来完全不同的形状，
- 竟然能给出一模一样的物理。
- 就像两把形状完全不同的乐器，
- 奏出了完全相同的音色。
- 这被称为“镜像对称”。

**第六幕 · 撕开再缝合**
- 他们还证明：在弦理论里，
- 空间的形状可以平滑地改变，
- 甚至撕开一个口子，再缝合起来，
- 物理却不会出问题。

**章节 · 讲述者**

**第七幕 · 康奈尔和哥伦比亚**
- 1990 年，他到康奈尔大学任教，
- 1996 年起，成为哥伦比亚大学的教授。

**第八幕 · 宇宙的琴弦**
- 1999 年，他写了一本书：《宇宙的琴弦》。
- 这本书入围了普利策奖，
- 后来被拍成美国公共电视台的纪录片，获得了皮博迪奖。
- 之后，他又写了《宇宙的结构》《隐藏的现实》《直到时间的尽头》。

**第九幕 · 科学节**
- 2008 年，他和一位前新闻制片人一起，
- 在纽约创办了“世界科学节”，
- 让科学家走上舞台，和普通人面对面。
- 他还在电影和电视剧里客串过，
- 在《生活大爆炸》里，演过他自己。

**结尾**
- 弦理论，到今天还没有被实验证实。
- 但他让很多人第一次觉得：
- 宇宙的最深处，也许像一首乐曲。

**回顾**：吉他弦 → 纽约 → 哈佛 → 牛津 → 基音和泛音 → 粒子是音符 → 卷起来的维度 → 镜像对称 → 撕开再缝合 → 康奈尔 → 哥伦比亚 → 宇宙的琴弦 → 世界科学节

## 值得记住（给用户）
- 两端固定弦的驻波：λₙ = 2L/n，fₙ = n·v/(2L)。**高中必考，必记。**
- 弦理论尚无实验证据——讲的时候要说清楚这是假说。

## 查证结果（2026-10-23 网页核对）
**已核实**
- 1963 年 2 月 9 日生于纽约市。
- 1984 年哈佛物理学士；罗德学者，牛津莫德林学院，1987 年哲学博士（页面信息框写 1986，正文写 1987，取正文）。
- 卡拉比-丘流形之间镜像对称的共同发现者；描述了翻转转变（flop transition）和锥形转变（conifold transition），证明弦理论中拓扑可以平滑改变。
- 1990 年加入康奈尔，1995 年正教授；1996 年起任哥伦比亚大学正教授，主持该校理论物理中心。
- 《宇宙的琴弦》（1999）入围普利策奖一般非虚构类；《宇宙的结构》（2004）、《隐藏的现实》（2011）、《直到时间的尽头》（2020）均为《纽约时报》畅销书。
- 《宇宙的琴弦》改编为 PBS NOVA 纪录片，获 2003 年皮博迪奖；《宇宙的结构》2011 年改编为四集 PBS 系列。
- 2008 年与前 ABC 新闻制片人特蕾西·戴共同创办世界科学节，并任主席。
- 电影《黑洞频率》（2000）技术顾问并客串；《最后的咪咪》（2007）客串；2011 年在《生活大爆炸》中本色出演。
